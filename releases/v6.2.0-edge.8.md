# Diagnostic bundles, anchored record comments, semantic graphs, and interactive diagrams

## TL;DR
Diagnostic Bundles for encrypted log export, anchored record comments with field security, a Semantic Graph substrate for Knowledge Hub, interactive architecture diagrams, permission-tiered conversation folders, and phone-optimized record forms. Plus agent harness, IS-A hydration and integration sync fixes.

**Upgrade Notes apply:** database migrations apply for diagnostics, comments, semantic graphs, and folder permissions, conversation folder access inheritance is opt-in, and `mj app install` pre-validates npm authentication.

Edge builds are prereleases.

MemberJunction 6.x is released under the [Business Source License 1.1](https://github.com/MemberJunction/MJ/blob/next/LICENSE); 5.x and earlier stay ISC. What the licence grants, and what needs certification, is in the [licence section of the v6 upgrade guide](https://github.com/MemberJunction/MJ/blob/next/UPGRADE-v6.0.md#license-change--read-this-first).

## New Features
- **Diagnostic Bundles** (`@memberjunction/diagnostics`, `@memberjunction/diagnostics-server`, `@memberjunction/ng-diagnostics`, `@memberjunction/cli`, `@memberjunction/ng-explorer-core`, `@memberjunction/server`, `@memberjunction/graphql-dataprovider`, `@memberjunction/global`): Adds end-to-end `.mjdiag` session export and intake for server logs, SQL statements, client network activity, telemetry, and breadcrumbs. Sessions use a two-stage scrubber, X25519 + AES-256-GCM envelope encryption, Ed25519-signed sender assertions (`MJDiag-Ed25519`), remote operations, and surfaces across the Explorer shell and the `mj diag` CLI tool.
- **Anchored record comments** (`@memberjunction/core`, `@memberjunction/core-entities`, `@memberjunction/core-entities-server`, `@memberjunction/ng-base-forms`, `@memberjunction/ng-conversations`, `@memberjunction/ng-core-entity-forms`, `@memberjunction/server`, `@memberjunction/integration-test-suite`): Adds field-, section-, and group-level record commenting (`<mj-record-comments>`) with persistent panel width user preferences, scroll-to-anchor navigation, and record-bound "Ask AI" conversations (`LinkedEntityID` and `LinkedRecordID`). Server enforcement includes post-`RunView` hooks on conversations, two-stage write-time field-level security classification via `AIPromptRunner` without leaking values, field-level security and row-level security-aware `@mention` notifications, and configurable per-entity comment permission gates (`MJ: Entities.Configuration.Comments.Enabled`).
- **Semantic Graph substrate** (`@memberjunction/core-entities`, `@memberjunction/core-entities-server`, `@memberjunction/server-bootstrap`, `@memberjunction/content-pipeline`, `@memberjunction/ai-core-plus`, `@memberjunction/ng-graph-view`, `@memberjunction/ng-dashboards`, `@memberjunction/integration-test-suite`): Introduces graph schema primitives (`MJ: Graph Types`, `MJ: Graph Concept Types`, `MJ: Graph Authority Tiers`, `MJ: Graphs`, `MJ: Graph Concepts`, `MJ: Graph Edge Types`, `MJ: Graph Edge Type Endpoints`, `MJ: Graph Edge Providers`, `MJ: Graph Edges`, and `ContentSource.GraphID`). Content Pipeline adds a `GraphStage` with `EntityGraphOverlayStore` and `DeterministicConceptSynthesizer`, `@memberjunction/ai-core-plus` adds deterministic `TaskGraph` DAG similarity and workflow health telemetry, and Knowledge Hub Visualize hosts the Semantic Graph & Canon Explorer UI.
- **Interactive architecture diagrams** (`@memberjunction/ai-diagrams`, `@memberjunction/ng-markdown`, `@memberjunction/core-actions`, `@memberjunction/ng-artifacts`): Validates and renders self-contained SVG architecture diagrams (workflow, sequence, lifecycle, dataflow) styled via `--mj-*` design tokens, with click-to-inspect viewer inspection and path tracing. `Render Architecture Diagram` and `Get Architecture Diagram Reference` actions join `Sage` and `Infographic Agent`, `mj-diagram` code fences render interactively in markdown, and the SVG artifact viewer runs in shadow DOM to isolate CSS.
- **Three-tier conversation folder permissions** (`@memberjunction/core-entities`, `@memberjunction/core-entities-server`, `@memberjunction/ng-conversations`, `@memberjunction/server`, `@memberjunction/server-bootstrap`): Adds Private (default), Shared (granted to users or roles via `MJ: Resource Permissions`), and Public permission tiers for conversation folders (`MJ: Projects`). A conversation in a shared folder is listed to entitled users only when its owner enables `inheritFolderAccess: true`; entity servers validate cycle prevention and owner-only folder or sharing mutations.
- **Metadata-driven agent trust and taint tracking** (`@memberjunction/ai-agents`, `@memberjunction/messaging-adapters`, `@memberjunction/actions-base`, `@memberjunction/actions`, `@memberjunction/core-actions`, `@memberjunction/ai-core-plus`): External ingestion actions declare `outputTrustLevel: "Untrusted"` in `MJ: Actions.Config`, wrapping untrusted output in `<untrusted_external_data>` tags, stripping directives from outputs, tracking tainted sources across sub-agents, and marking memory notes written during tainted runs as pending approval.
- **Structured error recovery and prompt stability** (`@memberjunction/ai-agents`, `@memberjunction/actions-base`, `@memberjunction/core-actions`): Adds `ActionErrorRecovery` payloads to action results with fuzzy entity and field suggestions on record mutation errors, classifies non-retryable permission and scope failures, and gates mid-loop message compaction on token thresholds to keep prompt prefixes stable for caching.
- **Phone-optimized record forms** (`@memberjunction/ng-base-forms`, `@memberjunction/ng-entity-viewer`): On screens 768px wide or smaller, the section rail opens as a searchable bottom sheet, the form toolbar auto-hides behind a toggle pill in read mode with `UserInfoEngine` toolbar visibility preferences, and the standard form toggle moves into the View sheet.

## Improvements
- **Zero-query IS-A entity hydration** (`@memberjunction/core`, `@memberjunction/sqlserver-dataprovider`, `@memberjunction/postgresql-dataprovider`): Resolves upward IS-A parent entity hydration and downward child discovery from in-memory engine and batch caches (`BaseEntity.LoadFromDataBatchAsISAParent`, `BaseEngineRegistry.FindCachedEntity`), collapses uncached disjoint subtype queries into single batched `RunViews` requests, and collects sibling view caches in a two-phase batch transformation.
- **Forced engine loads isolate new reads** (`@memberjunction/core`, `@memberjunction/aiengine`, `@memberjunction/tag-engine`, `@memberjunction/storage`, `@memberjunction/esignature`, `@memberjunction/web-search-engine`): `Config(true)` calls on `BaseEngine` and `SharedLoad` wait for any in-flight load to complete before re-reading, returning only data fetched after the forced load request.
- **Transaction group provider lifecycle integration** (`@memberjunction/core`, `@memberjunction/sqlserver-dataprovider`, `@memberjunction/postgresql-dataprovider`): Re-bases `SQLServerTransactionGroup` and `PostgreSQLTransactionGroup` on provider transaction methods, enabling nested savepoints, per-request provider isolation, transaction affinity propagation, deferred `RunAfterCommit` execution, and `OnSaveCompleted` events on group saves.
- **Foreign-key lookup error and timeout feedback** (`@memberjunction/ng-base-forms`): Foreign-key dropdown lookups that fail or exceed a configurable timeout (default 20s) display explicit error messages with a Retry action instead of infinite loading or empty states.
- **Deterministic integration test sharding** (`@memberjunction/testing-engine-base`, `@memberjunction/testing-engine`, `@memberjunction/testing-cli`, `@memberjunction/cli`): Adds `--transport=server|client|all` and `--shard=<index>/<total>` options to `mj test suite` for parallel multi-database test suite execution.
- **Realtime voice session credential resolution** (`@memberjunction/ai-prompts`, `@memberjunction/ai-agents`): Realtime sessions resolve API keys through the standard MJ Credentials fallback chain (`BaseModelRunner` / `ResolvePlatformAICredential`), logging specific vendor requirements when no key is found.
- **LiveKit telephony and PSTN audio isolation** (`@memberjunction/livekit-room-server`, `@memberjunction/telephony-adapters`, `@memberjunction/ng-livekit-room`, `@memberjunction/ng-mj-livekit-room`): Wires LiveKit SIP room teardown hooks, supports v2 camelCase SIP webhooks, adds PSTN passband comfort tones, and isolates microphone and audio streams during call hold.
- **MetadataSync pull and query extraction robustness** (`@memberjunction/core-entities-server`, `@memberjunction/metadata-sync`): `MJQueryEntityServer` resolves query SQL rows through the query's own provider, query extraction preserves manual parameters, and MetadataSync pull merges embeds by name.
- **Gemini 4 Argon price step-up and Qwen 3.8 27B** (`@memberjunction/core`): Encodes the 2026-12-01 price step-up for Gemini 4 Argon ($4.00/$20.00) in model metadata and seeds Qwen 3.8 27B in preview status.

## Bug Fixes
- **Integration sync page memory leak** (`@memberjunction/integration-engine`): `DetachString` copies string slices, unmapped column samples, and orphan detection record IDs, releasing parsed connector response pages after batch processing and saving over 2 GB of memory during large syncs.
- **Slack and Teams rapid message burst duplication** (`@memberjunction/messaging-adapters`): In-flight thread promises queue incoming messages per thread, preventing duplicate conversation creation and concurrent agent runs during message bursts.
- **`mj app install` and `upgrade` npm registry preflight** (`@memberjunction/open-app-engine`): Validates declared app packages against the npm registry before making file or database modifications, stopping with actionable instructions when npm authentication or package lookup fails.
- **Open App core schema isolation** (`@memberjunction/open-app-engine`): Reserves the configured core schema against app adoption or removal and downloads teardown scripts before running migrations so rollback proceeds offline.
- **`mj install` tag pinning and monorepo cloning** (`@memberjunction/installer`, `@memberjunction/cli`): `mj install` without explicit tags pins CLI, migrate, and codegen to the scaffolded release version, and monorepo installs clone release tags via `git clone --depth 1`.
- **`mj migrate` out-of-order execution across release lines** (`@memberjunction/cli`): Evaluates all unapplied versioned migrations above the database baseline row when upgrading across release lines, enabling `outOfOrder` execution automatically when pending core migrations exist.
- **IS-A hydration cache and subtype fixes** (`@memberjunction/core`): `FindCachedEntity` skips failed, denied, or uninstalled properties, batched child reads set `IgnoreMaxRows`, and child entities hydrate inherited mirror fields from the parent.
- **Streamed agent chunk payload size** (`@memberjunction/server`): Streamed agent progress chunks carry a lightweight run summary instead of full run objects holding every prompt step.
- **Dataset cache metadata reload race** (`@memberjunction/core`, `@memberjunction/generic-database-provider`): Prevents background metadata reloads and parent cascade deletes from corrupting cached row counts in `LocalCacheManager` and `DatasetCache`.
- **Entity deletion foreign key cleanup** (`@memberjunction/core`, `@memberjunction/codegen-lib`): `spDeleteEntityWithCoreDependencies` deletes entity `GraphEdge` rows and clears conversation anchor references before deleting entity records.
- **Inline markdown links open in new tabs** (`@memberjunction/ng-markdown`, `@memberjunction/ng-conversations`): Markdown rendered in conversation chats sets `target="_blank"` with `rel="noopener noreferrer"` by default.
- **Search tokenization and tag governance fixes** (`@memberjunction/search-engine`, `@memberjunction/content-autotagging`, `@memberjunction/tag-engine`, `@memberjunction/graphql-dataprovider`, `@memberjunction/server`, `@memberjunction/ng-dashboards`): Tokenizes multi-word search terms, handles client-supplied autotagging pipeline run IDs with heartbeat progress updates, exposes tag merge and co-occurrence mutations, and cleans up orphan tag references.

## Upgrade Notes
- **Database migrations apply on `mj migrate`**: Database schema updates land for `Metadata_Sync`, diagnostic sessions and sender registrations (`MJ: Diagnostic Sessions`, `Diagnostic Chunks`, `Diagnostic Bundles`, `MJ: Diagnostic Sender Registrations`), anchored conversation metadata (`AnchorType`, `AnchorKey`, `AnchorMetadata`, `IsResolved`, `ResolvedByUserID`, `ResolvedAt`), Semantic Graph entities (`MJ: Graph Types`, `MJ: Graph Concept Types`, `MJ: Graph Authority Tiers`, `MJ: Graphs`, `MJ: Graph Concepts`, `MJ: Graph Edge Types`, `MJ: Graph Edge Type Endpoints`, `MJ: Graph Edge Providers`, `MJ: Graph Edges`), and conversation folder permission backfills (`MJ: Projects`).
- **Conversation folder access inheritance is opt-in**: Conversation folders default to Private. Conversations placed in Shared or Public folders are visible only to their owner unless `inheritFolderAccess: true` is explicitly set in `AdditionalData`.
- **`mj app install` requires npm authentication**: `mj app install` and `upgrade` validate package availability on npm before executing. Run `npm login` if private package authentication fails.
- **Server package TypeScript declarations point to `dist`**: `@memberjunction/server` points its `types` entry and export condition at `dist/index.d.ts`, isolating consumers from internal TypeScript sources.
