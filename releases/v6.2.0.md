# Realtime task workflows, AI runner abstractions, and model updates

## TL;DR
Real-time task graph workflows with single-step folding and Command Center telemetry, specialized AI model runners for media, decisions, embeddings, reranking, and image generation, JSON Schema action parameter declarations, agent-vision consent for LiveKit meetings, and refreshed AI model metadata across major providers. Plus agent run audience controls, bound action parameters, runtime API key scoping, stop button turn continuation, and database provider fixes.

**Upgrade Notes apply:** integration API keys setting agent run scopes through GraphQL data require the new `agent:trusted` scope.

## New Features
- **AI Agent Workflows & Tasks Command Center and single-step graph folding** (`@memberjunction/ai-agents`, `@memberjunction/ai-core-plus`, `@memberjunction/ai-engine-base`, `@memberjunction/aiengine`, `@memberjunction/task-graph`, `@memberjunction/server`, `@memberjunction/conversations-runtime`, `@memberjunction/ng-conversations`, `@memberjunction/ng-tasks`, `@memberjunction/ng-explorer-core`, `@memberjunction/core`, `@memberjunction/generic-database-provider`): Adds single-step task graph folding that executes single-agent delegations inline within the turn without launching background task graphs while preserving artifact creation, per-user runnable agent directory caching (`GetUserRunnableAgentDirectory`), pre-submission task graph validation, isolated step artifact persistence, inline workflow execution cards with continuation banners, and a redesigned AI Agent Workflows & Tasks Command Center featuring KPI metrics, DAG waterfall timelines, and a step inspector drawer.
- **Specialized AI model runners for media, decisions, embeddings, reranking, and images** (`@memberjunction/ai`, `@memberjunction/ai-prompts`, `@memberjunction/ai-openai`, `@memberjunction/ai-elevenlabs`, `@memberjunction/ai-groq`, `@memberjunction/ai-heygen`, `@memberjunction/ai-reranker`, `@memberjunction/core-actions`, `@memberjunction/tag-engine`, `@memberjunction/ai-vector-dupe`, `@memberjunction/ai-vector-sync`, `@memberjunction/content-autotagging`, `@memberjunction/search-engine`): Introduces dedicated model runners extending `BaseModelRunner` that manage model selection, credential resolution, failover, and `MJ: AI Prompt Runs` telemetry across non-chat model types:
  - `AITextToSpeechRunner`, `AISpeechToTextRunner`, and `AIVideoRunner` with default carrier prompts (`Default Text To Speech`, `Default Speech To Text`, `Default Video Generation`) and split audio generator interfaces (`BaseTextToSpeech`, `BaseSpeechToText`).
  - `AIDecisionRunner` for typed likelihood, choice, and score decisions on `Decision`-type models with the `LLM Decision` model and `Default Decision` prompt.
  - `AIEmbeddingRunner` for vector embeddings with model/dimension-keyed caching, unpersisted stand-ins when no prompt is provided, and updated call sites across tag and search engines.
  - `AIImageGenerationRunner` for image generation failover and telemetry via the `Default Image Generation` prompt.
  - `AIRerankerRunner` for document and memory reranking using the `Default Rerank` prompt.
- **Action parameter JSON Schema declarations and native tool coercion** (`@memberjunction/core-entities`, `@memberjunction/ai-agents`, `@memberjunction/ai-prompts`, `@memberjunction/ai`, `@memberjunction/server`, `@memberjunction/ng-core-entity-forms`, `@memberjunction/testing-integration`): Adds `ActionParam.ValueSchema` to hold JSON Schema fragments (`type`, `description`, `enum`, `items`, `properties`, `required`) for action parameters. Tool builders emit the declared schema in place of coarse type mappings, argument coercion (`CoerceActionArguments`) validates arguments on all execution paths, prompt cascades honor native tool calling set on an agent's own prompt (`LLM.UseNativeToolCalling`), and all LLM models explicitly state `LLM.SupportsNativeToolCalling`.
- **Agent run audience restrictions** (`@memberjunction/ai-core-plus`, `@memberjunction/ai-agents`, `@memberjunction/actions-base`, `@memberjunction/actions`, `@memberjunction/core-actions`, `@memberjunction/integration-test-suite`): Bounds agent runs to a specified audience (`ExecuteAgentParams.Audience` with `Caller` or `Intersection` modes) so that run outputs and pre-execution RAG show only content visible to both the caller and every reader. Bounded runs withhold task graphs, reject unsupported actions with `AUDIENCE_UNSUPPORTED`, filter notes and examples to shared-only entries, and suppress client tools and memory persistence.
- **Trusted API key scope for agent run parameters** (`@memberjunction/server`): Introduces the `agent:trusted` API scope. Only callers using the system user or an API key holding the `agent:trusted` scope can set reserved run parameters (`PrimaryScopeEntityName`, `PrimaryScopeRecordID`, `SecondaryScopes`, `__agentTypePromptParams`) via `data`. Unscoped API keys and browser sessions have those reserved keys stripped from `data`.
- **LiveKit meeting agent-vision consent and controls** (`@memberjunction/ai`, `@memberjunction/livekit-room-server`, `@memberjunction/server`, `@memberjunction/graphql-dataprovider`, `@memberjunction/ai-realtime-client`, `@memberjunction/ng-realtime-media`, `@memberjunction/livekit-room-core`, `@memberjunction/integration-test-suite`): Adds the `SetLiveKitAgentVision` GraphQL mutation to record participant consent for camera and screen sharing with room agents, writes audit logs of type `Realtime Agent Vision Consent`, adds vision toggle buttons and "Agent can see" badges to media UI controls, and centralizes participant attributes (`REALTIME_AGENT_CAN_SEE_ATTRIBUTE`, `REALTIME_AGENT_WATCHES_ATTRIBUTE`) in `@memberjunction/ai`.
- **Decision steps in Agent Manager** (`@memberjunction/ai-agent-manager`, `@memberjunction/ai-core-plus`): Adds support for Decision steps in Agent Manager, updating architect and planning prompt templates, JSON output schemas, and configuration round-tripping for choice fork paths.
- **`compose:email` actionable command** (`@memberjunction/ai-core-plus`, `@memberjunction/ng-conversations`, `@memberjunction/messaging-adapters`, `@memberjunction/ng-explorer-core`): Adds the `compose:email` actionable command allowing agents to present pre-filled email drafts to the user. The UI opens the draft via a `mailto:` link or falls back to an open draft artifact with clipboard body copy when URL limits are exceeded, while Slack and Teams render channel-safe notifications.
- **AI model catalog expansion and vendor updates** (`@memberjunction/ai`, `@memberjunction/aiengine`, `@memberjunction/core-entities`, `@memberjunction/ai-elevenlabs`, `@memberjunction/ai-deepinfra`, `@memberjunction/ai-siliconflow`, `@memberjunction/ai-provider-bundle`, `@memberjunction/core`): Updates model metadata with new frontier models and providers:
  - Added models: Claude Opus 5.5, Claude Sonnet 5.5, Claude Haiku 5.5, GPT-6 Sol, GPT-6 Luna, GPT-6.1 Sol, GPT-6.1 Terra, Grok 4.7, Grok 4.6 (Azure Foundry), Grok Voice 3.0, Kimi K3.1 Pro & Pro Highspeed, MiniMax-M3.1-Flash, Mistral Large 4, Sakana AI (Fugu Max, Fugu Ultra v2), Xiaomi (MiMo V2.6 Pro & Flash via OpenRouter), Muse Spark Open, Muse Wonder, GLM-5.3-FlashX, ElevenLabs Eleven v4 and Eleven v4 Turbo, and Qwen 3.8 27B (preview).
  - Added inference drivers for DeepInfra (`DeepInfraLLM`) and SiliconFlow (`SiliconFlowLLM`).
  - Encoded scheduled Gemini 4 Argon price step-up effective 2026-12-01 ($4.00/$20.00).
  - Retired and expired obsolete routes including OpenAI's October 2026 shutdown wave (`o1`, `o1-pro`, `o3-mini`, `o4-mini`, `gpt-image-1`), Cerebras retired routes, Magistral 1.2, and inactive Google Gemini 1.5/2.5 preview routes.

## Improvements
- **Stop button and in-progress turn continuation** (`@memberjunction/ai-agents`, `@memberjunction/ai-core-plus`, `@memberjunction/ng-composer`, `@memberjunction/ng-conversations`, `@memberjunction/server`): Adds a Stop button for in-progress agent replies that cancels the run via an agent-run watchdog polling the run row while preserving completed steps. Subsequent turns automatically resume the stopped run's message stack and completed action results rather than starting over.
- **Bound action parameters for agent runs** (`@memberjunction/ai-core-plus`, `@memberjunction/ai-agents`, `@memberjunction/actions-base`, `@memberjunction/core-actions`, `@memberjunction/integration-test-suite`): Supports fixing action parameters (`ExecuteAgentParams.boundActionParams`) so specified input values are hidden from prompt catalogs and tool schemas and injected directly at dispatch, persisting bindings across continuation turns.
- **Agent run data trust markers** (`@memberjunction/ai-core-plus`, `@memberjunction/ai-agents`, `@memberjunction/server`, `@memberjunction/core-actions`, `@memberjunction/integration-test-suite`): Restricts scope and prompt parameter overrides (`PrimaryScopeEntityName`, `PrimaryScopeRecordID`, `SecondaryScopes`, `__agentTypePromptParams`) in `data` to trusted callers (`TrustReservedRunData`), stripping reserved parameters from untrusted GraphQL, MCP, and browser requests.
- **Runtime API key resolution for actions and realtime sessions** (`@memberjunction/ai`, `@memberjunction/ai-agents`, `@memberjunction/actions-base`, `@memberjunction/core-actions`, `@memberjunction/computer-use`, `@memberjunction/computer-use-engine`): Hands agent actions a scoped runtime API key resolver (`RunActionParams.RuntimeAPIKeyResolver`) so action steps (such as image generation) use the run's runtime credentials. Realtime voice sessions also resolve vendor keys against run API keys before platform defaults.
- **Agent catalog prompt narrowing** (`@memberjunction/ai-agents`): Adds `maxActionsInPrompt` and `maxSubAgentsInPrompt` configuration properties on agents to dynamically select and describe only the most relevant actions, sub-agents, and skills for an opening request.
- **Business Central connector connection lookups and accounting action rows** (`@memberjunction/actions-bizapps-accounting`): Enables accounting verbs (`CreateJournalEntry`, `GetChartOfAccounts`, `GetAccountBalances`, `GetDimensions`, `GetGLEntries`, `GetCustomers`, `GetSalesInvoices`) to target Business Central connections created by the Integrations connector using canonical aliases, optional `CompanyIntegrationID` parameters, and Entra ID client-credentials token management via `OAuth2TokenManager`. Backfills action metadata rows for all seven verbs.
- **Server-managed CloseReason on agent sessions** (`@memberjunction/core-entities-server`, `@memberjunction/server`, `@memberjunction/telephony-adapters`): Restricts session close reasons (`TimeLimit`, `Idle`, `Janitor`, `Shutdown`) to server-managed save paths, preventing client entity mutations from overriding automated session lifecycle status.
- **`SaveReturnMode` dialect abstraction** (`@memberjunction/generic-database-provider`, `@memberjunction/sqlserver-dataprovider`, `@memberjunction/postgresql-dataprovider`): Abstracts `SaveReturnMode` context resolution and datestamp selection into `GenericDatabaseProvider`, exposing dialect hooks implemented across SQL Server and PostgreSQL data providers.
- **Host-assigned search scopes and action changes** (`@memberjunction/actions-base`, `@memberjunction/ai-core-plus`, `@memberjunction/ai-agents`, `@memberjunction/search-engine`, `@memberjunction/core-actions`, `@memberjunction/action-runtime-host`, `@memberjunction/global`): Honors host-assigned search scope IDs (`SearchScopeIDs`) across sub-agents and tool dispatches, and respects `actionChanges` that remove all actions from an agent run.
- **File storage account tie-breaking fallback** (`@memberjunction/core-entities`, `@memberjunction/ai-engine-base`, `@memberjunction/aiengine`, `@memberjunction/ai-agents`): Resolves agent file storage account fallback by selecting the most recently updated active account when no explicit default storage account is configured.
- **Streamed agent chunk payload optimization** (`@memberjunction/server`): Replaces full agent run objects in streamed progress chunks with lightweight summaries, reducing payload size on long agent runs.

## Bug Fixes
- **Agent conversation response status race condition** (`@memberjunction/ai-agents`): Sequentializes progress message saves on a promise chain before saving final run status, preventing concurrent progress saves from overwriting final status updates and leaving conversation responses stuck in "In-Progress".
- **Vector index immediate cache update** (`@memberjunction/ai-engine-base`): Allows `AIEngineBase.VectorIndexes` to receive in-place cache updates on index save or delete, preventing cache misses in Knowledge Hub and autotagging engines.
- **Vendor spend cap failover and error classification** (`@memberjunction/ai`, `@memberjunction/ai-prompts`): Reclassifies vendor API usage limit errors (HTTP 400 usage limit responses) as `NoCredit` so prompts automatically fail over to alternative candidates instead of failing silently.
- **Dropped provider connection classification** (`@memberjunction/ai`, `@memberjunction/ai-gemini`): Inspects Node and undici error `cause` chains for socket reset and connection failure codes (`ECONNRESET`, `ENOTFOUND`), classifying dropped connections as `NetworkError` to trigger `NetworkOnly` prompt failover.
- **Agent artifact file storage resolution and SQL parameter escaping** (`@memberjunction/ai-agents`): Routes file-backed artifact downloads through `FileStorageEngine.ResolveFileObject` storage account validation and validates file IDs as UUIDs to prevent raw SQL interpolation.
- **Agent harness error and timeout stability** (`@memberjunction/ai-agents`, `@memberjunction/core-actions`, `@memberjunction/actions`, `@memberjunction/ai-openai`, `@memberjunction/ai-anthropic`): Ensures action failures maintain error context and prevents execution timeouts from corrupting agent run state.
- **Docker check flag in CLI agent initialization** (`@memberjunction/cli`): Fixes `mj agent init --skip-docker-check` so it skips the Docker availability probe and assumes Docker is running instead of marking Docker as unavailable.
- **AI diagrams wall-clock test ceiling** (`@memberjunction/ai-diagrams`): Adjusts wall-clock test thresholds on input validation checks to prevent false CI runner test failures under CPU load.

## Upgrade Notes
- **`agent:trusted` scope required for setting agent run scopes via GraphQL `data`** (`@memberjunction/server`): An integration API key that sets agent run scope parameters (`PrimaryScopeEntityName`, `PrimaryScopeRecordID`, `SecondaryScopes`, `__agentTypePromptParams`) inside the GraphQL `data` argument must be granted the `agent:trusted` API scope in `MJ: API Key Scopes`. Calls using keys without this scope will continue running under the key's user but will have reserved scope parameters stripped from `data`.
