# Predictive Studio honest training, durable task graphs, and metadata performance

## TL;DR
Predictive Studio introduces honest model training with immutable snapshot provenance and evaluation protocols, durable task execution graphs power resilient AI workflows, and stored entity programmatic names reduce metadata load times by up to 95%. Plus parameterized RunView filters, long-call realtime voice reconnects, and core engine performance optimizations.

**Upgrade Notes apply:** schema migrations update entity metadata columns and add database triggers for stored programmatic names.

Edge builds are prereleases.

## New Features
- **Predictive Studio honest training and evaluation framework** (`@memberjunction/predictive-studio-core`, `@memberjunction/predictive-studio`, `@memberjunction/predictive-studio-sidecar`, `@memberjunction/predictive-studio-truth-suite`, `@memberjunction/core`, `@memberjunction/core-entities`): Adds Prediction Units, Evaluation Protocols, immutable Training Snapshots with content hashing and per-value provenance tracking, rolling-origin backtesting, inner-CV selection, held-out permutation importance, leakage detection, and automated publication gates.
- **Durable task execution graphs and software factory core** (`@memberjunction/task-graph`, `@memberjunction/ai-agents`, `@memberjunction/ai-agent-manager`, `@memberjunction/core-actions`): Introduces durable task graphs with stateful step nodes, persistent execution state, automatic retries, and software factory workflow primitives for complex multi-agent orchestration.
- **Declarative entity lifecycle policies and scoped auto-numbering** (`@memberjunction/core`, `@memberjunction/server`): Enables declarative cross-entity policies, scoped document auto-numbering rules, and lifecycle policy engines that execute cross-entity validations and updates automatically during entity saves.
- **Parameterized RunView and fluent filter builder** (`@memberjunction/core`, `@memberjunction/graphql-dataprovider`, `@memberjunction/codegen-lib`): Adds `CompositeFilter` support in `RunView` and `BaseEngine`, a fluent `FilterOf<T>()` builder, parameterized filter SQL compilation with field-level security enforcement, and CodeGen-generated `TypedQuerySpec` descriptors with SHA-256 drift detection.
- **Long-call realtime voice reconnects and conversation continuity** (`@memberjunction/ai`, `@memberjunction/ai-realtime-client`, `@memberjunction/realtime-runtime`, `@memberjunction/ai-openai`, `@memberjunction/ai-gemini`, `@memberjunction/ai-xai`): Preserves state and audio continuity across transport drops and token refreshes for OpenAI, Gemini, xAI Grok Voice, ElevenLabs, AssemblyAI, and Inworld, separating replaceable ambient state snapshots from durable spoken turns.
- **Claude Mythos 5, Mythos 5.1, and GPT Image 2.6 Sunburst/Flare model support** (`@memberjunction/core`, `@memberjunction/ai`): Adds Anthropic's Claude Mythos 5 and Mythos 5.1 models alongside OpenAI's GPT Image 2.6 Sunburst and Flare generators to the model registry with active token and media pricing.

## Improvements
- **Stored entity programmatic names for metadata load acceleration** (`@memberjunction/core`, `@memberjunction/core-entities`, `@memberjunction/server`): Stores `CodeName`, `ClassName`, `BaseTableCodeName`, and `FieldCodeName` directly on `Entity` and `EntityField` table rows maintained by database triggers, dropping metadata load times on 39,000-field schemas from 11.5s to 0.5s.
- **Core engine memory and query performance optimization** (`@memberjunction/global`, `@memberjunction/core`, `@memberjunction/core-entities`): Excludes transient event payloads from global replay buffers, drains query coalescing via microtasks, memoizes user permissions per entity, fast-hydrates entities with `SkipNewRecord`, and indexes cached primary keys to eliminate full array scans.
- **PostgreSQL schema evolution and native column type preservation** (`@memberjunction/sql-dialect`, `@memberjunction/schema-engine`, `@memberjunction/integration-engine`): Preserves native SQL types (`INT`, `DECIMAL`, `BIT`, `UUID`, `DATETIMEOFFSET`) across schema syncs and dialect conversions, automatically generates non-unique indexes for soft keys, and maps unbounded string columns to `TEXT` on PostgreSQL.
- **Remote browser auto-open and form input filling** (`@memberjunction/ng-conversations`, `@memberjunction/remote-browser-cdp`): Automatically opens the Remote Browser side drawer when browser automation tools execute and adds inspected label matching for checkbox groups in `inPageFillFields`.
- **Value-list health audit tool for CLI** (`@memberjunction/cli`, `@memberjunction/standards`): Adds `mj doctor value-lists` to identify entity rows holding values outside their defined value lists and optionally update field definitions to permit user entry.

## Bug Fixes
- **Scheduler redispatch loop on active jobs** (`@memberjunction/scheduling-engine`): Skips running job entries during scheduled job dispatch ticks, preventing mid-run reloads from resetting `NextRunAt` and causing duplicate concurrent executions.
- **API key scope cache background refresh** (`@memberjunction/api-keys`, `@memberjunction/api-keys-base`, `@memberjunction/core`): Periodically re-reads API key scopes and permissions from the database every 60 seconds so deactivated keys or revoked scopes stop granting access without requiring a process restart.
- **Prototype pollution and log injection prevention** (`@memberjunction/global`, `@memberjunction/ai`, `@memberjunction/ai-agents`, `@memberjunction/ai-mcp-server`): Introduces `SafeDeepMerge` to strip `__proto__`, `constructor`, and `prototype` keys from AI configuration layers and agent JSON responses, and sanitizes CR/LF line breaks from user values before writing to log streams.
- **PostgreSQL procedure EXEC conversion and JSON text handling** (`@memberjunction/sql-converter`, `@memberjunction/cli`, `@memberjunction/integration-schema-builder`): Converts T-SQL `EXEC` statements inside procedure bodies to compatible PL/pgSQL function calls, handles `OUTPUT` parameters as `INOUT`, and creates `json` integration columns as `TEXT` to prevent type mismatch errors during PostgreSQL migration.
- **Open App CLI upgrade rollback on package failure** (`@memberjunction/open-app-engine`, `@memberjunction/cli`): Restores modified `package.json` files and lockfiles when package installation fails during `mj app upgrade`, leaving the application at its previous version state instead of marking it disabled.
- **AI Agent Action compact settings validation constraint** (`@memberjunction/core`, `@memberjunction/core-entities`): Corrects the generated validator for `CK_AIAgentAction_CompactSettingsOnlyWhenCompact` so rows with `ResultExpirationMode = 'Compact'` can be saved with compact settings.
- **Query description pass lost update on concurrent saves** (`@memberjunction/core-entities-server`): Re-reads query parameter rows after LLM completion before saving description updates, preventing server-set parameter flags applied during the wait from being overwritten.
- **Artifact viewer failure under row-level security** (`@memberjunction/ng-artifacts`): Filters collection and conversation link rows by held version IDs rather than executing a subquery against the base view, resolving "No artifact version found" errors for users with RLS filters.
