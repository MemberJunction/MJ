# API key scope refresh, cache sampling, and IS-A navigation fixes

## TL;DR
A patch release for the certified 6.1 LTS line that exports server magic-link helpers and fixes API-key scope cache refreshing. Additional fixes cover IS-A hierarchy tab navigation hangs, RLS-filtered artifact version views, and local cache size sampling.

## Improvements
- **MagicLinkService and token helpers exported for Open Apps** (`@memberjunction/server`): `MagicLinkService`, `HashToken` and `GenerateRawToken` are exported from the package root, allowing Open Apps to mint magic-link invites using the server's native token format and hashing logic instead of maintaining a separate copy.

## Bug Fixes
- **API-key scope tables re-read periodically from the database** (`@memberjunction/api-keys`, `@memberjunction/api-keys-base`, `@memberjunction/core`, `@memberjunction/integration-test-suite`): scope, application, and key-binding rows are re-read from the database every `scopeCacheTTLMs` (default 60 seconds), ensuring revoked scopes or deactivated applications stop granting access within one TTL rather than persisting until process restart. The refresh rebuilds the engine lookup maps directly from the database instead of the server cache. Expiry ticks in `BaseEngine` now survive failed loads, re-arm timers correctly, start after a failed initial load, stop when interval is set to 0, and unref expiry timers so they no longer prevent Node processes from exiting.
- **IS-A entity hierarchy tab navigation no longer freezes the browser** (`@memberjunction/ng-explorer-core`, `@memberjunction/ng-base-forms`): `ComponentCacheManager` now includes the entity discriminator in the cache key for `RecordResource` and `Records` tabs. Previously, because parent and child entities in an IS-A hierarchy share the exact same primary key (`recordId`), `ComponentCacheManager` omitted the entity discriminator and returned the detached parent component when requested for a child component. The tab container's reload check detected `existingEntity !== newEntity` and reloaded continuously, triggering an infinite synchronous reload loop that froze the browser tab. A cycle guard was also added to `MjFormToolbarComponent.ChildChain`.
- **Local cache size estimates cap sampling at 10 rows** (`@memberjunction/core`): `LocalCacheManager`'s size-estimation helper now serializes at most 10 sample rows when computing cache size. Previously, saving or deleting a single row in a large cached entity caused the estimator to serialize up to a tenth of all cached rows, introducing performance overhead during cache updates.
- **Artifact viewer opens records under row-level security filters** (`@memberjunction/ng-artifacts`): fixed an issue where users with row-level-security filtering on `MJ: Artifact Versions` received "No artifact version found" when trying to view an artifact. The viewer now filters collection and conversation-link rows using the version IDs already retrieved in memory rather than issuing a subquery on the `Artifact Versions` base view, which the API refuses for row-filtered users.
