# Comms V2, Predictive Studio Honest Serving, and Agent Prototype Inheritance

## TL;DR
Comms V2 introduces high-throughput email tracking and preference management, Predictive Studio adds the Honest Serving framework and durable model artifacts, Canon Graph Engine enables semantic graph pathfinding and concept approval gates, and AI Agents now support multi-level prototype inheritance and personal instances. Plus AssemblyAI voice integration, redesigned workflow debugging, zero-DB-read tracking routes, and agent circuit-breaker fixes.

**Upgrade Notes apply:** database migrations add Comms V2 and Predictive Studio tables.

Edge builds are prereleases.

What the licence grants, and what needs certification, is in the [licence section of the v6 upgrade guide](https://github.com/MemberJunction/MJ/blob/next/UPGRADE-v6.0.md#license-change--read-this-first).

## New Features
- **Comms V2 engine and high-throughput tracking** (`@memberjunction/communication-engine`, `@memberjunction/server`, `@memberjunction/ng-explorer-core`): Introduces the Comms V2 messaging engine supporting transactional and marketing emails, SendGrid and MJServer route integration, compliance gates, subscriber preference centers, admin management UIs, and zero-database-read tracking endpoints for open pixels and link clicks.
- **Predictive Studio Honest Serving framework** (`@memberjunction/predictive-studio-core`, `@memberjunction/predictive-studio-server`, `@memberjunction/core-entities`): Delivers the Honest Serving architecture featuring a central Model Registry, lifecycle gate verification, write-once fingerprinted model artifacts, a dedicated Scoring Service, monitoring engine, and direct storage of predictions as Feature Values.
- **Canon Graph Engine and Semantic Graph** (`@memberjunction/canon-graph-engine`, `@memberjunction/core-entities`, `@memberjunction/server`): Adds semantic graph pathfinding, Concept Approval gates, `GraphAccessPolicy` edge redaction rules, deterministic domain proposals, and automatic indexing of MemberJunction documentation within the graph.
- **AI Agent instances and prototype inheritance** (`@memberjunction/ai-agents`, `@memberjunction/ai-core-plus`, `@memberjunction/ng-conversations`): Enables personal and shared AI Agent instances using multi-level prototype inheritance (`BaseAgentID`), exclusive primary instance synchronization, 2x2 RBAC with SQL Row-Level Security (`UserAccessibleAIAgents`), user-keyed default chat agent preferences, and the unified My Agents application.
- **AssemblyAI native voice integration** (`@memberjunction/ai-assemblyai`, `@memberjunction/ai-engine-base`): Provides direct native integration with AssemblyAI for real-time speech recognition, transcription, and streaming audio processing.

## Improvements
- **Workflows UX redesign and step breakpoint debugging** (`@memberjunction/ng-task-graph-editor`, `@memberjunction/task-graph`): Redesigns the visual task-graph workflow editor with interactive step debugging, persistent step breakpoints per user and workflow, and strict workflow UUID compliance.
- **Zero-DB-read tracking routes for open and click metrics** (`@memberjunction/server`): Optimizes open-pixel (`/track/open`) and link-click (`/track/click`) tracking routes by bypassing database reads during request handling to deliver maximum throughput under high traffic volume.
- **Pluggable scope dimension resolution** (`@memberjunction/search-engine`): Exposes `ScopeDimensionResolverBase` via `ClassFactory` to allow custom domain extensions for search scope dimension resolution.
- **Multi-account harness pool and CLI subscription auth** (`@memberjunction/ai-agent-harness`, `@memberjunction/cli`): Adds multi-account pool management for agent harnesses and CLI login authentication handling for subscription auth.
- **DB AutoDoc gating and linear parameter substitution** (`@memberjunction/db-auto-doc`, `@memberjunction/integration-schema-builder`): Hardens primary and foreign key gating, linear parameter substitution, sampling statistics reuse, and automatic column description generation.

## Bug Fixes
- **Agent payload change holding and tool circuit breakers** (`@memberjunction/ai-agents`): Holds refused completion payload changes instead of discarding them to prevent lost edits during multi-turn validation, and adds run-scoped tool circuit breakers to stop repeating failing tool calls.
- **Agent feedback request foreign-key race resolution** (`@memberjunction/ai-agents`, `@memberjunction/ai-core-plus`): Resolves a race condition where an agent request row was inserted before its originating step's save landed by ensuring `createFeedbackRequest` waits for `AgentRunStepSaveQueue` to settle.
- **Agent channel null reference error logging** (`@memberjunction/core-actions`): Emits clear error messages when agent channel entities cannot be created due to pending database migrations instead of throwing generic null reference exceptions.
- **Stop All conversation run ownership restriction** (`@memberjunction/ai-core-plus`, `@memberjunction/ng-conversations`): Restricts the "Stop All" conversation action to stop only runs initiated by or belonging to the active user.
- **PostgreSQL counterpart migrations for v6.3.0-edge.2** (`@memberjunction/sql-converter`, `@memberjunction/migrations-pg`): Generates PostgreSQL counterpart migrations for all T-SQL migrations and `Metadata_Sync` updates added in `v6.3.0-edge.2`.

## Upgrade Notes
- **Comms V2 and Predictive Studio database migrations**: Run `mj migrate` to apply database migrations that create tables and views for Comms V2 (`MJ: Communications`, subscriber preferences) and Predictive Studio (`MJ: ML Models`, `MJ: ML Scoring Runs`, `MJ: Feature Values`).
