# Content Pipeline Phase 1, Video Studio features, and local embedding optimizations

## TL;DR
Content Pipeline Phase 1 introduces automated web content discovery, Playwright crawling, and chunk-level vector embeddings, Video Studio adds audio ducking, word cues, and parallel capture, and Open Apps can now be installed from local folders. Plus opt-in saved-query metadata loading, ONNX memory optimizations for local embeddings, and realtime voice session resume fixes.

**Upgrade Notes apply:** database migrations add Content Pipeline tables and update entity metadata permissions.

Edge builds are prereleases.

## New Features
- **Content Pipeline Phase 1 for web content discovery and ingestion** (`@memberjunction/content-pipeline`, `@memberjunction/core-entities`, `@memberjunction/server`): Introduces Content Items as an IS-A extension of products, automated Playwright-based web page discovery and crawling, HTML extraction, resumable discovery walks, decorator-driven re-segmentation, and chunk-level vector embedding status tracking.
- **Video Studio audio ducking, word cues, and parallel capture** (`@memberjunction/video-studio`, `@memberjunction/ai-agents`): Adds audio ducking, loudness normalization, automated audio checks, custom pronunciation dictionaries, word cue timing, procedural audio tracks, and parallel video/audio capture pipelines.
- **Local folder installation for Open Apps** (`@memberjunction/open-app-engine`, `@memberjunction/cli`): Supports installing and validating Open Apps directly from local workspace directory paths in addition to git repository URLs.

## Improvements
- **Opt-in saved-query metadata loading** (`@memberjunction/core`, `@memberjunction/server`, `@memberjunction/graphql-dataprovider`): Moves saved-query metadata fetching on `Metadata` to an opt-in model controlled by the per-request `LoadQueryMetadata` setting, reducing default GraphQL and server request payload sizes.
- **ONNX CPU memory optimization for AI local embeddings** (`@memberjunction/ai-local-embeddings`): Disables the ONNX CPU memory arena during local embedding operations, saving ~1 GB of RAM during syncs, and adds automatic model release when tokenizer setup fails or model max length limits are reached.
- **Gemini 4 Hydrogen native tool calling support** (`@memberjunction/ai-gemini`, `@memberjunction/core-entities`): Updates Gemini 4 Hydrogen model metadata rows to indicate `SupportsNativeToolCalling = true`, enabling native tool call execution for Gemini 4 models.
- **Class-based engine and singleton keying** (`@memberjunction/global`, `@memberjunction/core`): Keys global singletons and deferred engines by their constructor class reference instead of string names, preventing name mangling during minification from corrupting singleton lookups.

## Bug Fixes
- **Realtime session state preservation and voice model restoration on resume** (`@memberjunction/ai-realtime-client`, `@memberjunction/realtime-runtime`, `@memberjunction/ng-conversations`): Preserves `ArtifactWorkspace` state, target agent names, multi-leg channel configurations, and selected voice models across session pauses and resumes.
- **Open App path traversal and symlink restriction** (`@memberjunction/open-app-engine`): Rejects `mj-app.json` link paths that reference directories outside the application root directory or attempt out-of-repository symlink traversals.
- **Standby remote browser tool re-initialization** (`@memberjunction/remote-browser-cdp`, `@memberjunction/ng-conversations`): Re-prepares standby remote browser tools when the conversation drawer closes and preserves remote browser viewport dimensions on drawer resizes.
- **Bare video/mp4 MSE frame rendering and AudioContext resume** (`@memberjunction/ai-realtime-client`): Accepts bare `video/mp4` Media Source Extension frames without initialization headers and automatically resumes suspended browser `AudioContext` instances on user interaction.
- **PostgreSQL counterpart migrations for v6.3.0-edge.1** (`@memberjunction/sql-converter`, `@memberjunction/migrations-pg`): Generates PostgreSQL counterparts for all pre-cut SQL Server migrations in `v6.3.0-edge.1`, including `Metadata_Sync` writebacks and entity permission updates.
