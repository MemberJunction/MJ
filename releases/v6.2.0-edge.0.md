# Gemini 3.8 Live, provider-neutral search, and Mobile v6

## TL;DR
Gemini 3.8 Live brings full-duplex multimodal audio/video streaming, provider-neutral Web Search failover decouples agents from specific vendors, and Mobile app v6 lands with a shared realtime-voice engine and native layout navigation. Plus Predictive Studio outcomes, Feature Pipelines constraint validation, and citizen agent builder tools.

**Upgrade Notes apply:** eleven schema migrations apply on `mj migrate`, `realtime.enabled` is flipped to `true` by default, and Google Custom Search and Perplexity Search are no longer bound by default to agents/skills.

Edge builds are prereleases.

## New Features
- **Gemini 3.8 Live multimodal realtime streaming** (`@memberjunction/ai-gemini`, `@memberjunction/ai-realtime-client`, `@memberjunction/ai`, `@memberjunction/ai-agents`, `@memberjunction/remote-browser-server`, `@memberjunction/ng-conversations`, `@memberjunction/server-bootstrap-lite`): Adds comprehensive, full-duplex support for Google's `gemini-3.8-live` and `gemini-3.8-live-extended-thinking` models. This includes a first-class media plane supporting audio/video tracks, non-blocking tool execution, thought summaries mapped to separate narration cards, and resilient session resumption.
- **Provider-neutral Web Search with priority failover** (`@memberjunction/web-search-engine`, `@memberjunction/core-actions`): Introduces a single, stable `Web Search` Action that routes queries across a new prioritized table of search providers (including Brave, Perplexity, Tavily, Google, and DuckDuckGo). Users are shielded from underlying vendor deprecations or rate limits, as the engine dynamically shifts to active fallback options.
- **Citizen agent builder workspace and initialization** (`@memberjunction/cli`, `@memberjunction/installer`): Delivers the `mj agent init` command and a citizen agent builder template workspace, establishing a structured 11-step local engineering loop backed by automated native CLI step auditing.
- **Predictive Studio overhaul with high-polish Graph View** (`@memberjunction/core`, `@memberjunction/predictive-studio-core`, `@memberjunction/ng-dashboards`, `@memberjunction/ng-explorer-core`, `@memberjunction/ng-shared`): Redesigns the user experience around an enterprise AG Grid, slide-in historical trendlines, model score explainability, and outcome polarity config using mathematically clean, half-open interval score bands.
- **Feature Pipelines and Entity Documents extraction** (`@memberjunction/feature-pipelines`, `@memberjunction/entity-documents`): Adds declarative schema migrations, constraint validation, content hashing, watermarks, and target validations, enabling automated prompt context construction from rich record states.

## Improvements
- **Mobile app v6 complete integration** (`@memberjunction/mobile-app`, `@memberjunction/realtime-runtime`, `@memberjunction/conversations-runtime`, `@memberjunction/ng-conversations`): Migrates the entire chat layer to the shared conversations runtime, coordinates React Native WebRTC drivers to enable seamless real-device voice calls, parses hosted application navigation directly from database metadata, and adds secure Own-Agent-Session row-level security.
- **Failover on vendor credit spend caps** (`@memberjunction/ai`, `@memberjunction/ai-prompts`): Classifies spend limits and credit exhaustion from API responses as `NoCredit` rather than generic `InvalidRequest` blocks, allowing prompt execution to fail over to the next configured candidate model rather than failing silently.
- **Change-driven browser screencast deduplication** (`@memberjunction/remote-browser-server`, `@memberjunction/ai-gemini`): Introduces frame hashing and deduplication with a fallback 15-second heartbeat, saving approximately 15,000 tokens per minute of static screen viewing while maintaining sub-second reactivity upon user interaction.

## Bug Fixes
- **Client-side search returned nothing on servers without a read-only database login** (`@memberjunction/server`): The `SearchEntities` resolver requested the read-only provider with no fallback, so on the common deployment with no `dbReadOnlyUsername` configured every `SearchEntity`/`SearchEntities` call over GraphQL came back empty. It now falls back to the read-write provider.
- **Queries comparing to a quoted template value lost their field extraction** (`@memberjunction/sql-parser`): SQL such as `WHERE Name = '{{ VendorName }}'` or `LIKE '%{{ Term }}%'` had its template value quoted a second time during parsing, so the SQL failed to parse and a saved Query derived no field rows. Template values inside an existing string literal are now substituted without extra quotes.
- **Records saved in a rolled-back transaction no longer stay cached** (`@memberjunction/core`): `BaseEngine` applied cache changes as soon as a record's own write returned, so a save inside a transaction that later rolled back stayed in engine caches for the life of the process. Cache changes raised inside an open transaction now apply on commit and are dropped on rollback.
- **Deferred cache mutations match on pre-delete primary keys** (`@memberjunction/core`): Ensures that BaseEngine cache mutations deferred inside an open transaction use the pre-delete primary key values when committed, preventing deleted records from remaining cached as zombie rows.
- **PostgreSQL synchronization handles create-or-update T-SQL block translation** (`@memberjunction/sql-converter`): Parses and converts conditional T-SQL `IF NOT EXISTS` upsert patterns emitted by `mj sync push` into safe PL/pgSQL structures, unblocking PostgreSQL database sync compliance during deployment cycles.
- **Attachments service decoupled from server-only packages** (`@memberjunction/aiengine`, `@memberjunction/ng-conversations`, `@memberjunction/server`): Places media blob uploads behind a client-compatible `IAttachmentBlobStore` seam, resolving bundle-time loader crashes on browser/mobile surfaces while forcing large files to go to storage instead of blowing up database rows.

## Upgrade Notes
- **Eleven schema migrations apply on `mj migrate`**: This release adds 11 SQL Server and PostgreSQL migrations including the `spDeleteEntityWithCoreDependencies` hardening, task-graph procedures, the removal of 25 obsolete computer-use Test records, and feature pipeline structures.
- **Default configuration for `realtime.enabled` is flipped to `true`**: Enables the `/realtime/sdp-exchange` WebRTC broker endpoint by default across all servers, which can be opted-out using the `MJ_REALTIME_ENABLED=false` environment variable.
- **`Web Search` Action is now a provider-neutral router**: Direct agent bindings to `Google Custom Search` and `Perplexity Search` have been removed in favor of the routing search action. Google is retiring its Custom Search API on 2027-01-01, and Microsoft retired Bing Search in 2025; existing databases will lose these bindings during metadata migration.
