MJ Elements Phase 0: what collides on one page

Every embeddable MJ element on one plain page. The cards are the hostile host under test (serif, its own colors, !important on every button); bundles load in order, and the log records singletons, zone.js, fonts, style bleed, layout and CSP nonces at every step.

<mj-realtime-widget> A

bundles/mj-realtime-widget/mj-realtime-widget.js (classic script; the call code is an ES module fetched on start). Built in MJ: packages/Angular/Generic/realtime-widget, `pnpm run build`.

<mj-realtime-widget> B, in a parent with no definite height, no csp-nonce attribute, preload="eager"

Same bundle, second instance. Its nonce must come from somewhere else on the page; its preload link shows which.

<mj-support-widget>

bundles/mj-support-widget/mj-widget.js (ES module). Built in MJ: packages/Web/RealtimeWidget, `pnpm run build` then the esbuild line in README.md. The loader mints a guest session before it mounts the element; with no server that fails, so the page mounts one by hand to measure the shadow DOM. Add ?support=keepnames for the keep-names build.

<mj-form>

bundles/mj-form/mj-form.js (classic script). Built in a sibling clone of bizapps-forms, packages/Angular, and copied in by sync-bundles.mjs (README.md). Zoneless; MJ core is kept out by a build gate.

<mj-orders-checkout>

bundles/mj-orders-checkout/main.js (ES module, not minified). Built in a sibling clone of bizapps-orders, packages/Angular, and copied in by sync-bundles.mjs (README.md). Ships zone.js. Reads its nonce off the first <mj-orders-checkout>, so this one carries one.

<caliber-widget>, in a parent with no definite height

bundles/caliber-widget/caliber-widget.js (classic script, one 16 MB file). Built in a sibling clone of bizapps-caliber (internal repo), packages/Angular, and copied in by sync-bundles.mjs (README.md). Zoneless; carries MJ core from npm and creates MJGlobal at load.
