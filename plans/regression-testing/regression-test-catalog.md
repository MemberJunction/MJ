# MJExplorer Regression Test Catalog

Reference for all **380** Computer-Use regression tests (T001–T380). Each test drives the
real MJExplorer UI (authenticated at `http://localhost:4200`) toward a natural-language **Goal**; an LLM
judge then verifies the **Checks**. Tests are written to be *data-agnostic* — they assert that a feature
behaves, not that specific rows exist, so they pass on empty-states.

**Priority:** P0 = 6 · P1 = 95 · P2 = 207 · P3 = 72

**T001 · Login Smoke** `P0 · smoke`
- **Goal:** Verify the MJ Explorer dashboard or home screen has loaded successfully with navigation elements visible.
- **Checks:** User is logged in and past the Auth0 login screen; MJ Explorer application is visible with navigation elements; No error messages or blank screens

**T003 · Application Switcher** `P0`

**T006 · Navigation and Tab Management** `P0`

Verify switching between the Home tab and the record tab works and each shows its own content. (You do NOT need multiple record tabs — this verifies tab navigation between Home and an open record.) Pages can take 10-30s to load — wait, don't navigate away.
- **Checks:** A record opened as a workspace tab alongside the Home tab; Switching between the Home tab and the record tab works, each showing its own content; No error messages, blank screens, or crash pages

**T009 · Handle Invalid Navigation Gracefully** `P3`

Reaching the Home page after the invalid URL counts as graceful handling.
- **Checks:** User navigated to an invalid/nonexistent path; Application displayed an error page or redirected gracefully; Application did NOT show a blank white screen or crash
