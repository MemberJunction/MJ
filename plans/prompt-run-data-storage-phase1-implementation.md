# Prompt-run data storage (MJ#5526 phase 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prompt runs store the messages the model received, and store template inputs (`data`, `templateData`) only as the capture mode allows: `None` (key sizes, the default), `Referenced` (keys the templates use) or `Full`.

**Architecture:** A new `AIPrompt.TemplateDataCapture` column, an `AIPromptParams.TemplateDataCapture` call override, and an mj.config server default choose the mode. `AIPromptRunner` builds the stored `Messages` object through one pure helper module. `Referenced` asks the template engine for the variables a template reads; the engine parses the template with Nunjucks and walks the AST. Readers (CorePlus `ParseMessagesData`, the Explorer prompt-run form, two integration checks) learn the new shape.

**Tech Stack:** TypeScript, Nunjucks 3.2.4 parser, cosmiconfig 9, Angular 18 (Explorer forms), Vitest, SQL Server migration + MJ CodeGen.

**Spec:** `plans/prompt-run-data-storage-and-step-redaction.md` (§3 is phase 1; decisions D1–D7). Read §3 before your task.

```ts
import type { ChatMessage } from '@memberjunction/ai';
import type { MJAIPromptEntity } from '@memberjunction/core-entities';

/**
 * Which template inputs (`data`, `templateData`) a prompt run stores in `AIPromptRun.Messages`:
 * - `None`: their shape only (top-level keys and byte sizes)
 * - `Referenced`: only the keys the run's templates read
 * - `Full`: everything that was passed
 */
export type TemplateDataCaptureMode = NonNullable<MJAIPromptEntity['TemplateDataCapture']>;

/** Every capture mode. */
export const TEMPLATE_DATA_CAPTURE_MODES: readonly TemplateDataCaptureMode[] = ['None', 'Referenced', 'Full'];

/** True when `value` is one of {@link TEMPLATE_DATA_CAPTURE_MODES} (case-sensitive). */
export function IsTemplateDataCaptureMode(value: string | null | undefined): value is TemplateDataCaptureMode {
    return value != null && (TEMPLATE_DATA_CAPTURE_MODES as readonly string[]).includes(value);
}

/** Most top-level keys a shape record lists per object; the same limit as the action log's redaction record. */
export const MAX_TEMPLATE_DATA_SHAPE_KEYS = 25;

/** Shape of one template-input object: key names and sizes, never values. */
export interface TemplateDataObjectShape {
    /** Number of top-level keys. */
    keyCount: number;
    /** Sum of the UTF-8 JSON byte lengths of all top-level values (values that cannot be serialized count as 0). */
    totalBytes: number;
    /** Top-level key → UTF-8 byte length of its value's JSON form; -1 when the value cannot be serialized. */
    keys: Record<string, number>;
    /** True when `keys` lists only the {@link MAX_TEMPLATE_DATA_SHAPE_KEYS} largest values. */
    keysElided?: boolean;
}

/** Shapes of a run's template inputs. An input the caller did not pass has no entry. */
export interface TemplateDataShape {
    data?: TemplateDataObjectShape;
    templateData?: TemplateDataObjectShape;
}

/** Parallel-execution summary stored on a consolidated (`ParallelParent`) prompt run. */
export interface StoredParallelExecutionInfo {
    parallelizationMode: MJAIPromptEntity['ParallelizationMode'];
    totalTasks: number;
    successfulTasks: number;
    failedTasks: number;
    selectedTaskId: string;
    executionGroups: number[];
}

/** The JSON object `AIPromptRunner` writes to `AIPromptRun.Messages`. */
export interface StoredPromptRunMessages {
    /** The capture mode applied to this run. */
    dataCapture: TemplateDataCaptureMode;
    /** Why the applied mode differs from the requested one (a `Referenced` run stored as `Full`). */
    dataCaptureNote?: string;
    /** Set in `None` mode when the caller passed `data` or `templateData`. */
    dataShape?: TemplateDataShape;
    /** Set in `Referenced` and `Full` mode when the caller passed `data`. */
    data?: Record<string, unknown>;
    /** Set in `Referenced` and `Full` mode when the caller passed `templateData`. */
    templateData?: Record<string, unknown>;
    /** Set on consolidated parallel runs. */
    parallelExecution?: StoredParallelExecutionInfo;
    /** The messages the model received. */
    messages: ChatMessage[];
}
```

  - `interface ReferencedVariablesResult { Names: ReadonlySet<string>; Complete: boolean; Reason?: string }`
  - `CollectReferencedVariables(templateText: string, options: ReferencedVariablesOptions): ReferencedVariablesResult`
  - `TemplateEngineServer.GetReferencedVariables(templateText: string): ReferencedVariablesResult`

**Facts (probed against nunjucks 3.2.4 in this repo):**
- `nunjucks.parser.parse(src, extensions)` returns a `Root` node. Every node has `typename` and a `fields` array naming its child properties; `NodeList`/`Root` keep children in `children`.
- `Symbol` nodes carry top-level variable names (`{{ user.email }}` → `Symbol user`; the `email` part is a `Literal`). Loop, `set`, filter and keyword-argument names are also `Symbol`s; that is harmless because the runner keeps only names that are data keys.
- `Include`, `Import`, `FromImport` and `Extends` keep the template name in field `template` (`Literal` when it is a string literal).
- `{% template "Name", type="HTML" %}` parses (with the extension registered) to `CallExtensionAsync` with `extName === 'TemplateEmbed'` and `args.children[0]` the name node. `extName` is the registration key because `env.addExtension(key, ext)` sets `ext.__name`.
- `@types/nunjucks` does not declare `parser`; declare it by module augmentation.
- MJ's loader resolves `{% include %}` by template ID, not by name, so resolve every literal name with `FindTemplate(name)` (case-insensitive name lookup). A name that does not resolve makes the result incomplete, which makes the runner store `Full`. That is the safe direction.

```ts
import { describe, it, expect } from 'vitest';
import type nunjucks from 'nunjucks';
import { CollectReferencedVariables, type ReferencedVariablesOptions } from '../TemplateVariableAnalysis';

interface EmbedParser { nextToken(): { value: string }; parseSignature(a: null, b: boolean): object; advanceAfterBlockEnd(name: string): void }
interface EmbedNodes { CallExtensionAsync: new (ext: object, prop: string, args: object) => object }

/** Same parse as TemplateEmbedExtension; `__name` is what env.addExtension would set. */
const embedExtension = {
    __name: 'TemplateEmbed',
    tags: ['template'],
    parse(parser: EmbedParser, nodes: EmbedNodes) {
        const tok = parser.nextToken();
        const args = parser.parseSignature(null, true);
        parser.advanceAfterBlockEnd(tok.value);
        return new nodes.CallExtensionAsync(this, 'run', args);
    },
} as nunjucks.Extension;

function options(templates: Record<string, string[]> = {}): ReferencedVariablesOptions {
    return { Extensions: [embedExtension], ResolveTemplateTexts: (name) => templates[name.toLowerCase()] ?? null };
}

describe('CollectReferencedVariables', () => {
    it('collects top-level names from output, loops, conditions and filters', () => {
        const r = CollectReferencedVariables('{% for r in rows %}{{ r.name }}{% endfor %}{% if user %}{{ user.email | upper }}{% endif %}{{ _CURRENT_PAYLOAD | dump }}', options());
        expect(r.Complete).toBe(true);
        for (const n of ['rows', 'r', 'user', '_CURRENT_PAYLOAD']) expect(r.Names.has(n)).toBe(true);
        expect(r.Names.has('name')).toBe(false);
        expect(r.Names.has('email')).toBe(false);
    });

    it('parses custom tags and follows a literal {% template %} embed', () => {
        const r = CollectReferencedVariables('{% template "Child", type="HTML" %}{{ a }}', options({ child: ['{{ childVar }}'] }));
        expect(r.Complete).toBe(true);
        expect(r.Names.has('a')).toBe(true);
        expect(r.Names.has('childVar')).toBe(true);
    });

    it('follows literal include, import and from-import, across every content of the target', () => {
        const r = CollectReferencedVariables('{% include "Inc" %}{% import "M" as m %}{% from "F" import g %}', options({
            inc: ['{{ incVar }}', '{{ incVarHtml }}'], m: ['{{ mVar }}'], f: ['{{ fVar }}'],
        }));
        expect(r.Complete).toBe(true);
        for (const n of ['incVar', 'incVarHtml', 'mVar', 'fVar']) expect(r.Names.has(n)).toBe(true);
    });

    it('stops on a cycle without failing', () => {
        const r = CollectReferencedVariables('{% include "A" %}', options({ a: ['{{ aVar }}{% include "B" %}'], b: ['{{ bVar }}{% include "A" %}'] }));
        expect(r.Complete).toBe(true);
        expect(r.Names.has('aVar')).toBe(true);
        expect(r.Names.has('bVar')).toBe(true);
    });

    it('is incomplete for a template named by an expression', () => {
        const inc = CollectReferencedVariables('{% include someVar %}', options());
        expect(inc.Complete).toBe(false);
        expect(inc.Reason).toMatch(/expression/);
        const embed = CollectReferencedVariables('{% template dyn %}', options());
        expect(embed.Complete).toBe(false);
    });

    it('is incomplete when a named template is not found', () => {
        const r = CollectReferencedVariables('{% include "Missing" %}', options());
        expect(r.Complete).toBe(false);
        expect(r.Reason).toContain('"Missing"');
    });

    it('is incomplete when the text does not parse', () => {
        const r = CollectReferencedVariables('{% for x in %}', options());
        expect(r.Complete).toBe(false);
        expect(r.Reason).toMatch(/could not be parsed/);
    });

    it('is incomplete when a custom tag has no registered extension', () => {
        const r = CollectReferencedVariables('{% template "Child" %}', { Extensions: [], ResolveTemplateTexts: () => null });
```

```ts
export type NunjucksAstValue = NunjucksAstNode | NunjucksAstValue[] | string | number | boolean | null | undefined;

/** The parts of a nunjucks AST node this analysis reads. `fields` names the node's child properties. */
export interface NunjucksAstNode {
    readonly typename: string;
    readonly fields: readonly string[];
    readonly [field: string]: NunjucksAstValue | readonly string[];
}

declare module 'nunjucks' {
    /** The template parser. nunjucks exports it; @types/nunjucks does not declare it. */
    export const parser: {
        parse(src: string, extensions?: Extension[]): NunjucksAstNode;
    };
}

/** Variables a template reads. */
export interface ReferencedVariablesResult {
    /** Top-level names the template and the templates it pulls in read. Also holds loop, `set`, filter and keyword names. */
    Names: ReadonlySet<string>;
    /** False when part of the template could not be analyzed, so `Names` may miss entries. */
    Complete: boolean;
    /** Why `Complete` is false. */
    Reason?: string;
}

/** Inputs for {@link CollectReferencedVariables}. */
export interface ReferencedVariablesOptions {
    /** Extensions whose custom tags the parser must understand. */
    Extensions: nunjucks.Extension[];
    /** Texts of every content of the stored template with this name, or null when there is no such template. */
    ResolveTemplateTexts: (templateName: string) => string[] | null;
}

/** Tags that pull in another template; the name is in their `template` field. */
const TEMPLATE_REFERENCE_NODES = new Set(['Include', 'Import', 'FromImport', 'Extends']);
/** Registration key of the `{% template %}` embed extension. */
const TEMPLATE_EMBED_EXTENSION = 'TemplateEmbed';

interface WalkState {
    names: Set<string>;
    problems: string[];
    visitedTemplates: Set<string>;
    options: ReferencedVariablesOptions;
}

/**
 * Parses a Nunjucks template and returns the top-level variable names it reads, following stored
 * templates it pulls in by literal name. A template named by an expression, a name that does not
 * resolve, or text that does not parse makes the result incomplete.
 */
export function CollectReferencedVariables(templateText: string, options: ReferencedVariablesOptions): ReferencedVariablesResult {
    const state: WalkState = { names: new Set(), problems: [], visitedTemplates: new Set(), options };
    collectFromText(templateText, state);
    return state.problems.length === 0
        ? { Names: state.names, Complete: true }
        : { Names: state.names, Complete: false, Reason: state.problems.join('; ') };
}

function collectFromText(text: string, state: WalkState): void {
    let root: NunjucksAstNode;
    try {
        root = nunjucks.parser.parse(text, state.options.Extensions);
    } catch (error) {
        state.problems.push(`template could not be parsed: ${error instanceof Error ? error.message : String(error)}`);
        return;
    }
    walk(root, state);
}

function isAstNode(value: NunjucksAstValue | readonly string[]): value is NunjucksAstNode {
    return typeof value === 'object' && value !== null && !Array.isArray(value) && typeof (value as NunjucksAstNode).typename === 'string';
}

function walk(value: NunjucksAstValue | readonly string[], state: WalkState): void {
    if (Array.isArray(value)) {
        for (const item of value) walk(item, state);
        return;
    }
    if (!isAstNode(value)) return;
    if (value.typename === 'Symbol' && typeof value.value === 'string') {
        state.names.add(value.value);
    }
    if (TEMPLATE_REFERENCE_NODES.has(value.typename)) {
        followTemplate(value.template, value.typename, state);
    }
    if ((value.typename === 'CallExtension' || value.typename === 'CallExtensionAsync') && value.extName === TEMPLATE_EMBED_EXTENSION) {
        const args = value.args;
        const first = isAstNode(args) && Array.isArray(args.children) ? args.children[0] : undefined;
        followTemplate(first, 'template', state);
    }
    for (const field of value.fields) {
        walk(value[field], state);
    }
}

function followTemplate(nameNode: NunjucksAstValue | readonly string[], tag: string, state: WalkState): void {
    if (!isAstNode(nameNode) || nameNode.typename !== 'Literal' || typeof nameNode.value !== 'string') {
        state.problems.push(`a {% ${tag.toLowerCase()} %} tag names its template with an expression`);
        return;
    }
    const name = nameNode.value;
    const key = name.trim().toLowerCase();
    if (state.visitedTemplates.has(key)) return;
    state.visitedTemplates.add(key);
    const texts = state.options.ResolveTemplateTexts(name);
    if (!texts) {
        state.problems.push(`template "${name}" was not found`);
        return;
    }
    for (const text of texts) collectFromText(text, state);
}
```

```ts
import { LogWarning } from '@memberjunction/core';
import type { ChatMessage } from '@memberjunction/ai';

    IsTemplateDataCaptureMode,
    MAX_TEMPLATE_DATA_SHAPE_KEYS,

    type StoredPromptRunMessages,

export const CURRENT_PAYLOAD_DATA_KEY = '_CURRENT_PAYLOAD';

/** Capture mode when no call, prompt or server setting applies. */
export const DEFAULT_TEMPLATE_DATA_CAPTURE: TemplateDataCaptureMode = 'None';

/** The `aiPromptRuns` section of mj.config.cjs. */
export interface AIPromptRunsConfig {
    /** Server default capture mode: 'None', 'Referenced' or 'Full'. */
    templateDataCapture?: string;
}

/** Picks the capture mode: the call override, then the prompt's setting, then the server default. Invalid values are skipped. */
export function ResolveTemplateDataCaptureMode(
    callOverride: string | null | undefined,
    promptSetting: string | null | undefined,
    serverDefault: TemplateDataCaptureMode,
): TemplateDataCaptureMode {
    if (IsTemplateDataCaptureMode(callOverride)) return callOverride;
    if (IsTemplateDataCaptureMode(promptSetting)) return promptSetting;
    return serverDefault;
}

/** Reads `aiPromptRuns.templateDataCapture` from mj.config. A missing value gives 'None'; an invalid one logs a warning and gives 'None'. */
export function ReadServerTemplateDataCaptureDefault(searchFrom: string = process.cwd()): TemplateDataCaptureMode {
    let section: AIPromptRunsConfig | undefined;
    try {
        const result = cosmiconfigSync('mj', { searchStrategy: 'global' }).search(searchFrom);
        section = result && !result.isEmpty ? (result.config?.aiPromptRuns as AIPromptRunsConfig | undefined) : undefined;
    } catch (error) {
        LogWarning(`aiPromptRuns.templateDataCapture: mj.config could not be read (${error instanceof Error ? error.message : String(error)}); using '${DEFAULT_TEMPLATE_DATA_CAPTURE}'`);
        return DEFAULT_TEMPLATE_DATA_CAPTURE;
    }
    const value = section?.templateDataCapture;
    if (value === undefined || value === null) return DEFAULT_TEMPLATE_DATA_CAPTURE;
    if (IsTemplateDataCaptureMode(value)) return value;
    LogWarning(`aiPromptRuns.templateDataCapture '${String(value)}' is not None, Referenced or Full; using '${DEFAULT_TEMPLATE_DATA_CAPTURE}'`);
    return DEFAULT_TEMPLATE_DATA_CAPTURE;
}

/** UTF-8 byte length of a value's JSON form; -1 when it cannot be serialized. */
function jsonByteLength(value: unknown): number {
    try {
        const json = JSON.stringify(value);
        return json === undefined ? 0 : Buffer.byteLength(json, 'utf8');
    } catch {
        return -1;
    }
}

/** Shape of one template-input object: top-level key names and value sizes, the largest 25 when there are more. */
export function BuildTemplateDataObjectShape(obj: Record<string, unknown>): TemplateDataObjectShape {
    const sizes = Object.entries(obj).map(([key, value]): [string, number] => [key, jsonByteLength(value)]);
    const elided = sizes.length > MAX_TEMPLATE_DATA_SHAPE_KEYS;
    const listed = elided ? [...sizes].sort((a, b) => b[1] - a[1]).slice(0, MAX_TEMPLATE_DATA_SHAPE_KEYS) : sizes;
    const shape: TemplateDataObjectShape = {
        keyCount: sizes.length,
        totalBytes: sizes.reduce((sum, [, size]) => sum + Math.max(size, 0), 0),
        keys: Object.fromEntries(listed),
    };
    if (elided) shape.keysElided = true;
    return shape;
}

/** A copy without the agent payload key; the same object when the key is absent. */
function withoutCurrentPayload(obj: Record<string, unknown> | undefined): Record<string, unknown> | undefined {
    if (!obj || !(CURRENT_PAYLOAD_DATA_KEY in obj)) return obj;
    const copy = { ...obj };
    delete copy[CURRENT_PAYLOAD_DATA_KEY];
    return copy;
}

function pickKeys(obj: Record<string, unknown>, names: ReadonlySet<string>): Record<string, unknown> {
    return Object.fromEntries(Object.entries(obj).filter(([key]) => names.has(key)));
}

/** Inputs for {@link BuildStoredPromptRunMessages}. */
export interface StoredPromptRunMessagesInput {
    /** The resolved capture mode. */
    Mode: TemplateDataCaptureMode;
    Data?: Record<string, unknown>;
    TemplateData?: Record<string, unknown>;
    /** The messages the model received. */
    Messages: ChatMessage[];
    /** Variables the run's templates read. Called only in `Referenced` mode. */
    GetReferencedVariables: () => ReferencedVariablesResult;
    ParallelExecution?: StoredParallelExecutionInfo;
}

/**
 * Builds the object stored in `AIPromptRun.Messages`. `_CURRENT_PAYLOAD` is never stored. `None` stores
 * a shape record, `Referenced` the keys the templates read (or everything, with a note, when the analysis
 * is incomplete), `Full` everything.
 */
export function BuildStoredPromptRunMessages(input: StoredPromptRunMessagesInput): StoredPromptRunMessages {
    const data = withoutCurrentPayload(input.Data);
    const templateData = withoutCurrentPayload(input.TemplateData);
    let dataCapture: TemplateDataCaptureMode = input.Mode;
    let dataCaptureNote: string | undefined;
    let dataShape: TemplateDataShape | undefined;
    let storedData: Record<string, unknown> | undefined;
    let storedTemplateData: Record<string, unknown> | undefined;

    if (input.Mode === 'None') {
        if (data || templateData) {
            dataShape = {};
            if (data) dataShape.data = BuildTemplateDataObjectShape(data);
            if (templateData) dataShape.templateData = BuildTemplateDataObjectShape(templateData);
        }
    } else if (input.Mode === 'Referenced') {
        const referenced = input.GetReferencedVariables();
        if (referenced.Complete) {
            storedData = data && pickKeys(data, referenced.Names);
            storedTemplateData = templateData && pickKeys(templateData, referenced.Names);
        } else {
            dataCapture = 'Full';
            dataCaptureNote = `Referenced capture stored all data: ${referenced.Reason ?? 'the template analysis was incomplete'}`;
            storedData = data;
            storedTemplateData = templateData;
        }
    } else {
        storedData = data;
        storedTemplateData = templateData;
    }

    // Assigned in this order so the large `messages` array is serialized last.
    const stored: Omit<StoredPromptRunMessages, 'messages'> = { dataCapture };
    if (dataCaptureNote !== undefined) stored.dataCaptureNote = dataCaptureNote;
    if (dataShape !== undefined) stored.dataShape = dataShape;
    if (storedData !== undefined) stored.data = storedData;
    if (storedTemplateData !== undefined) stored.templateData = storedTemplateData;
    if (input.ParallelExecution !== undefined) stored.parallelExecution = input.ParallelExecution;
    return { ...stored, messages: input.Messages };
}
```

```ts
    prompt: MJAIPromptEntityExtended,
    params: AIPromptParams,
    messages: ChatMessage[],
    parallelExecution?: StoredParallelExecutionInfo,
  ): string {
    const mode = ResolveTemplateDataCaptureMode(params.TemplateDataCapture, prompt.TemplateDataCapture, this.GetServerTemplateDataCaptureDefault());
    return JSON.stringify(BuildStoredPromptRunMessages({
      Mode: mode,
      Data: params.data,
      TemplateData: params.templateData,
      Messages: messages,
      GetReferencedVariables: () => this.collectReferencedVariables(prompt, params),
      ParallelExecution: parallelExecution,
    }));
  }

  /** Variables read by the prompt's template and by every child prompt template rendered in the same run. */
  private collectReferencedVariables(prompt: MJAIPromptEntityExtended, params: AIPromptParams): ReferencedVariablesResult {
    const names = new Set<string>();
    const problems: string[] = [];
    const addPromptTemplate = (templateId: string | null, promptName: string): void => {
      if (!templateId) return;
      const template = this._templateEngine.Templates.find((t) => UUIDsEqual(t.ID, templateId));
      const text = template?.GetHighestPriorityContent()?.TemplateText;
      if (!text) {
        problems.push(`the template of prompt "${promptName}" was not found`);
        return;
      }
      const result = this._templateEngine.GetReferencedVariables(text);
      result.Names.forEach((name) => names.add(name));
      if (!result.Complete) problems.push(`prompt "${promptName}": ${result.Reason ?? 'incomplete analysis'}`);
    };
    const addChildren = (children: ChildPromptParam[] | undefined): void => {
      for (const child of children ?? []) {
        addPromptTemplate(child.childPrompt.prompt.TemplateID, child.childPrompt.prompt.Name);
        addChildren(child.childPrompt.childPrompts);
      }
    };
    addPromptTemplate(prompt.TemplateID, prompt.Name);
    addChildren(params.childPrompts);
    return problems.length === 0 ? { Names: names, Complete: true } : { Names: names, Complete: false, Reason: problems.join('; ') };
  }
```
