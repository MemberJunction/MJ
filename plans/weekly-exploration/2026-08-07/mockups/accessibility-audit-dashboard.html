AI-Proposed — review before applying
Status dot conveys meaning by color alone
WCAG 1.4.1 requires that color not be the only visual means of conveying information. A colorblind user (≈8% of men) cannot distinguish the red "At Risk" dot from the green "Active" dot. Pairing the color with an icon and text fixes this for every generated grid that uses StatusIndicatorComponent.
- <span class="status-dot" [style.background]="color"></span> + <span class="status-dot" [style.background]="color"> + <i [class]="icon" aria-hidden="true"></i> + </span> + <span class="sr-only">{{ statusLabel }}</span>
Proposed change lives in packages/Angular/Generic/ui-components/status-indicator — fixing this one component resolves the finding on 14 generated surfaces.
