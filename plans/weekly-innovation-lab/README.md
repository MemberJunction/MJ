# Weekly Innovation Lab

A recurring exercise: study the MemberJunction repo deeply (architecture, recent merged PRs, active
`plans/` initiatives, open PRs, open issues) alongside the outside world (association/nonprofit tech
landscape, sector-wide pressures, adjacent agentic-AI platform trends), then propose creative new
directions for how MJ can make life better for the associations and nonprofits it serves.

**Format:** one session per week, three ideas per session, each with a full written plan and a
self-contained HTML/CSS mockup. Ideas are explicitly designed to sit *above* active infrastructure
work, not duplicate it.

**Scope note:** Every idea produced so far is an **application-layer** proposal — each one requires
an association's or nonprofit's data to already be in MJ (members, donations, volunteer hours, grant
obligations, etc.) before the feature can deliver value. They are not framework-level improvements
to MJ's core platform. In the next iteration of this exercise we will deliberately shift focus to
**framework-level ideas** — improvements to MJ's core capabilities (data access, CodeGen, agent
infrastructure, Open App mechanics, etc.) that benefit any developer or deployer of MJ regardless
of the application built on top.
