How the Orders App Makes "Overview" the Top Left-Nav Item

In MemberJunction, when an app (like Orders) is installed, it registers a BaseFormPanel with @RegisterClassEx(BaseFormPanel, { metadata: { entity: 'MJ_BizApps_Common: People', slot: 'before-fields', sortKey: 100, contributionKey: 'overview' } }). In left-nav mode, this panel claims the top-priority slot above default fields, rendering as the initial active dashboard tab. Site admins can override via MJ: Form Chrome Rules, but the app provides this out-of-the-box!
