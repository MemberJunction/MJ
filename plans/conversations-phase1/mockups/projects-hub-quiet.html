Project Hub — Quiet Execution

A refinement of the picked direction (Option A / canvas C1), not a new direction. Same thesis: a project is a place you open. The change is discipline: one focal point per screen, hierarchy from type and space instead of cards and chips, counts removed, actions revealed on hover, and chrome that earns its place as the project grows. Two frames: what v1 ships, and the same page grown. Toggle your OS theme for dark.

Frame 1

Hub at v1 — conversations + memory + share, nothing else

The v1 scope the density pushback asked for, executed quiet: no tab bar (the overview IS the page), no stat line, no cards, no chips, one primary action. Resume is the first row, emphasized by content, not by a banner.

Workflows, artifacts, and members appear here when those ship — nothing renders empty. Sparse projects stay this calm forever.

The moves:
Stat line deleted — the counts repeated the tabs, the tabs repeated the sidebar.
No tab bar at v1 — with only conversations + memory, the overview IS the page. Tabs arrive with content (Frame 2).
Cards → sections. Whitespace and small-caps labels carry the hierarchy; zero boxes-in-boxes.
Resume is the first row with a "Continue" affordance — content emphasis, not a tinted banner. Kills the toll booth.
Memory chips (ALL AGENTS / PROJECT / SAGE) → muted suffix text. Edit/forget reveal on hover (middle row shows the hover state).
Inline composer removed — one primary action ("New chat"), one place. The composer lives in the conversation, not on the landing.
One accent color moment per screen: the Continue link. Everything else is text-primary/muted.

Tradeoff: the hub carries less at-a-glance state (no counts, no member avatars at v1). That's deliberate — orientation comes from reading three real conversation summaries, not from counting badges. If usage shows people miss a count, add it to the tab label in Frame 2, never back to a stat line.

Frame 2

The same hub, grown — satellites arrive as quiet rows, not new dashboards

Workflows and artifacts have shipped; the project is shared. The page keeps the same skeleton: tabs appear (plain labels, no icons, no counts), "Running now" earns a slot only while something runs, artifacts are rows, members are an avatar stack in the header. Density grows; noise doesn't.

The growth contract:
Tabs appear only now — plain text labels, no icons, no count badges. Deep-linkable homes without the scoreboard.
"Running now" exists only while something runs. Idle workflows don't rent space on the overview; history lives behind the Gantt link.
One workflow row = dot + name + thin bar + muted meta. No status pills, no per-row agent chips.
Artifacts are reading rows, not icon tiles. Monochrome glyphs; version and age as muted text.
Members = avatar stack beside Share. The Members tab is the management surface; the header just shows presence.
Memory trimmed to the two most relevant notes on Overview; the full list lives in the Memory tab.

Open questions for review: does Overview cap each section at 2–3 rows with the tab as the full surface (drawn here), or grow unbounded? And when nesting is ratified (the six hierarchy questions), child projects would slot in as another quiet section — same row language — but that stays undrawn until the review settles it.
