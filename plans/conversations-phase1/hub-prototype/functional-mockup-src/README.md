# Functional Mockup — extracted source mirror

Diffable source of `../MJ Composed Shell - Functional Mockup.html` (which is a self-extracting
bundle and opaque to git diffs). `template.html` = markup + CSS; `app.js` = the app script.
The BUNDLE is the runnable artifact of record; this mirror exists so every correction pass
lands as a reviewable diff. After any new pass: re-extract (script blocks: #1 = gzip/base64
asset manifest, #4 = JSON-encoded template) and refresh both files here in the same commit.
Font assets are not mirrored (embedded in the bundle; not design content).
