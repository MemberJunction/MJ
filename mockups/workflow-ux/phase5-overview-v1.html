Workflow UX — Phase 5 mockups (v1, for iteration)

Four views of one idea: the same canvas authors a workflow, watches it run, and receives promoted agent plans. Terminology per D18 — users see “Workflow”; Flow Agent stays under the hood. Layout, spacing and color are directional, not final.

Open questions for iteration: ① toolbar vs. per-node placement for the concurrency cap · ② should the recovery path style (dashed amber) also cover Validate-rejection routes, or do those get their own color · ③ run view: right-panel activity feed vs. bottom timeline strip · ④ does “Save as Workflow” in chat prompt for name/trigger immediately, or drop you into the editor first · ⑤ minimap & palette collapsed by default on smaller screens?
