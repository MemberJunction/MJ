# @memberjunction/record-cloning

Core execution engine for MemberJunction record cloning:
- **ClonePlanner**: Graph-aware deterministic cloning plan computation.
- **CloneMaterializer**: Entity graph instantiation via collections and dynamic declarations.
- **CloneExecutor**: Transactional composite save, provenance ledger, and post-clone actions.
- **CloneRecordProcessor**: Remote operation shell handlers.
