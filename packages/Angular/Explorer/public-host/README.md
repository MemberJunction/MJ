# @memberjunction/ng-public-host

Public pages for MJ Explorer: pages that a visitor can open before signing in, such as a product landing page or a pricing page. Open Apps ship them; the public host renders them at `/p/<slug>`.

A public page does not load Explorer, the auth SDK, GraphQL or metadata. It loads Angular, this package and its own chunk. A host can start it in two ways: from a hook in Explorer's `main.ts`, or from a separate public build.

## How it starts

The host app's `main.ts` calls `TryStartPublicPage` first. It starts Explorer only when the call returns false:

```ts
import { TryStartPublicPage } from '@memberjunction/ng-public-host/bootstrap';
import { environment } from './environments/environment';
import { PUBLIC_PAGES } from './app/generated/public-pages.generated';

async function initAndBootstrap() {
  if (await TryStartPublicPage({ Environment: environment, PublicPages: PUBLIC_PAGES })) {
    return;
  }
  // The host's own Explorer start-up.
}
```

- A path under `/p/` starts the public host and returns true. The host finds the page for the slug, loads its chunk and renders it. An unknown slug shows "Page not found".
- Every other path returns false at once, and `main.ts` starts Explorer as before.
- In `main.ts`, load code that only Explorer needs (the auth preload helpers, `platformBrowserDynamic`) with a dynamic import. A public page also downloads every static import of `main.ts`.

`PUBLIC_PAGES` is generated by `mj codegen manifest --public-pages <file>` from the `publicPages` entries that `mj app install` writes into `mj.config.cjs`.

## The separate public build

MJ Explorer's build also writes a small public build to `dist/MJExplorer/browser/public-host/` (the `MJPublicPages` project in its `angular.json`). Its `main.ts` calls `StartPublicHost` directly. It has its own `index.html` with no files from other sites, only the MJ design tokens as global styles, and no zone.js.

To use it, add one rule to the web host: send every `/p/*` address to `/public-host/index.html`.

Azure Static Web Apps (`staticwebapp.config.json`, already in MJ Explorer):

```json
"routes": [{ "route": "/p/*", "rewrite": "/public-host/index.html" }]
```

nginx:

```nginx
location /p/ {
    try_files /public-host/index.html =404;
}
```

- Without the rule, Explorer's `index.html` answers `/p/` addresses and the hook in `main.ts` shows the page. Pages do not change between the two.
- Explorer's service worker does not answer `/p/` addresses, so the web host receives them also from a visitor who used Explorer before.
- `pnpm start` serves only Explorer, so in development public pages start through the hook.

## Writing a public page

A public page is a standalone component that extends `BasePublicPage`:

```ts
import { Component } from '@angular/core';
import { BasePublicPage } from '@memberjunction/ng-public-host';

@Component({
  selector: 'acme-pricing-page',
  template: `
    <h1>Pricing</h1>
    <button type="button" (click)="Context.StartSignIn()">Sign in</button>
  `,
})
export class PricingPageComponent extends BasePublicPage {}
```

`Context` (a `PublicPageContext`) gives the page:

| Member | What it is |
|---|---|
| `Slug`, `SubPath`, `QueryParams` | The parts of the URL after `/p/` |
| `Brand()` | The sign-in page design from Login Studio (logos, theme), or `null` |
| `BuildMJAPIURL(path)` | An absolute URL for the Open App's `pre-auth` server endpoints |
| `StartSignIn()` | Opens Explorer's sign-in screen. A new visitor signs up there when the identity provider allows it |

Rules for a public page:

- Get data only from the Open App's `pre-auth` server endpoints. There is no session and no GraphQL client.
- Export the page from a package entry that does not import the app's Explorer code, so the page chunk stays small.
- Use MJ design tokens for colours. The host runs without zone-based change detection, so use signals for state.
- Bring the page's own styles and icons. The separate public build loads only the MJ design tokens: not Explorer's global styles and not Font Awesome.
- Set the document title yourself (`inject(Title)`).

Declare the page in the Open App's `mj-app.json`:

```json
"publicPages": [
  { "slug": "pricing", "package": "@acme/app-public", "export": "PricingPageComponent", "title": "Pricing" }
]
```
