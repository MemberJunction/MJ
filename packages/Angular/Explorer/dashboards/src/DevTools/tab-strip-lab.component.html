Both strips draw from the one global .mj-tabs* stylesheet and get their keyboard behaviour from the one mjTabList directive. Any visual or behavioural difference between the two below is a bug in that sharing, not a styling choice. Keyboard: Tab into a strip (it is a single tab stop), then ←/→ to move, Home/End for the ends, Delete to close a closeable tab.

<mj-tabstrip>

projected children · addressed by index · owns its bodies
@for (label of ProjectedLabels; track label) { {{ label }} } @for (label of ProjectedLabels; track label) {
Body for {{ label }}
 }

<mj-workspace-tab-strip>

data array · addressed by id · projects nothing · drag to reorder
@if (Store.ActiveTab) { Body for {{ Store.ActiveTab.Label }} status: {{ Store.ActiveTab.Status }}{{ Store.ActiveTab.Dirty ? ' · unsaved' : '' }} } @else { No tab selected — close them all to see the empty state. }
