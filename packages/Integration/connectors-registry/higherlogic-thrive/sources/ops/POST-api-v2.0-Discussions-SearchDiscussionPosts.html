POST api/v2.0/Discussions/SearchDiscussionPosts

Returns Discussion Post information that meet the search criteria.

Request Information

URI Parameters

None.

Body Parameters

"SearchString": Any Search String, "PostedSince and PostedBefore": Allow setting of Boundary Dates for the search, "AuthorInfo": Limit search by Author Details, "MaxDescriptionLength": Max Characters to return for the Description, "MaxToRetrieve": Max Records to Retrieve, "DiscussionKeyList": Comma-separated list of DiscussionKeys to Limit the Search To, "SortField": One of (date, subject) defaults to date, "SortOrder": Either desc or asc - defaults to desc
