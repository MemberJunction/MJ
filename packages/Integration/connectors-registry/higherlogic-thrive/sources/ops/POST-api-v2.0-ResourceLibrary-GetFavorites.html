POST api/v2.0/ResourceLibrary/GetFavorites

Returns a list of Favorited Documents.

Request Information

URI Parameters

None.

Body Parameters

SortOrder: (Optional) Can be one of: "views", "document_title", "rating". If none is specified, the default sort order is by descending date of when the document was favorited. MaxRecords: (Optional) Maximum records to retrieve. Defaults to 50 if not specified.
