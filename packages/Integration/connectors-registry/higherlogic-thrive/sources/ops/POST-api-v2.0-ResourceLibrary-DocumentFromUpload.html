POST api/v2.0/ResourceLibrary/DocumentFromUpload

Using the ObjectKey returned when initiated the upload, creates a resource library entry once the file upload is complete and has been reconstituted (if necessary).

Request Information

URI Parameters

None.

Body Parameters

Contains the key of the library to assign the document to, details for the document being created, and details for the individual files to associate to that document, including the objectKey of the previously uploaded file.

CompleteDirectUploadRequest
NameDescriptionTypeAdditional information
LibraryKey

Unique guid that identifies the library in which to create a new library entry (document).

 globally unique identifier

Required
Title

Title of the library entry (document).

 string

Required
Description

Description of the library entry (document).

 string

Required
TopicTagKeys

One or more keys that identify topic tags to associate to the library entry (document) when posted to a topic community's library. Omit when not posting to a topic community's library.

 Collection of globally unique identifier

None.
Files

Set of information for individual files that have been directly uploaded to associate to this library entry (document).

 Collection of CompleteDirectUploadFileRequest

Required

Min length: 1
