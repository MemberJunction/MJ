POST api/v2.0/Events/RSVPToEvent?eventKey={eventKey}

RSVPs the current user to the designated event. For events with a registration type of RSVP only, not valid for other registrations. Registering for a parent repeating event also registers you for all following occurrences.

Request Information

URI Parameters

NameDescriptionTypeAdditional information
eventKey

Unique identifier of the event to RSVP to.

 globally unique identifier

Required

Body Parameters

None.

Response Information

Resource Description

EventRegistrant
NameDescriptionTypeAdditional information
RegistrantKey

Unique Key for the Registrant.

 globally unique identifier

None.
BadgeName

Name to display on the Registrant's Badge.

 string

None.
Contact

Contact detail for the Registrant.

 Contact

None.
PaymentStatus

Status detail for the Registrant's payment. Will indicate whether the Registrant has paid, or if payment is still due.

 string

None.
RegistrationStatus

Status detail for the Registration. Indicates whether the registration for the event is: Completed, Incomplete, Abandoned, Canceled, Balance Due.

 string

None.
ModifiedDate

Last modified date (UpdatedOn) for the Registrant.

 date

None.
