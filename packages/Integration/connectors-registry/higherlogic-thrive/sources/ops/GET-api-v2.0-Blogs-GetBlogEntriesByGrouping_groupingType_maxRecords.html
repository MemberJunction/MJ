GET api/v2.0/Blogs/GetBlogEntriesByGrouping?groupingType={groupingType}&maxRecords={maxRecords}

Retrieves Blog Entries by the specified GroupingType.

Request Information

URI Parameters

NameDescriptionTypeAdditional information
groupingType

Can be one of the following string values: "my_blogs", "my_contacts", "most_recent", "top_rated", "most_read", "unpublished". One of these values *must* be included.

 string

Required
maxRecords

Number of Blog Entries to retrieve. Defaults to 20 if no value is specified.

 integer

Default value is 20

Body Parameters

None.
