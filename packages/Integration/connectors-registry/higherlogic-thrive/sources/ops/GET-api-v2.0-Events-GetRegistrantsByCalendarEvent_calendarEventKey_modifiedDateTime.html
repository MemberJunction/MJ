GET api/v2.0/Events/GetRegistrantsByCalendarEvent?calendarEventKey={calendarEventKey}&modifiedDateTime={modifiedDateTime}

Administrator-accessible only endpoint. Returns Registrant Data for a given Calendar Event and optionally a modified datetime can be passed in to only get updated registrants.

Request Information

URI Parameters

NameDescriptionTypeAdditional information
calendarEventKey

Required. Unique Identifier for a Calendar Event.

 globally unique identifier

Required
modifiedDateTime

Optional. The format is "yyyy-MM-ddTHH:mm:ss". If specified only registrants that have been modified since this date will be returned.

 date

None.

Body Parameters

None.

Response Information

Resource Description

Collection of EventRegistrant
NameDescriptionTypeAdditional information
RegistrantKey

Unique Key for the Registrant.

 globally unique identifier

None.
BadgeName

Name to display on the Registrant's Badge.

 string

None.
Contact

Contact detail for the Registrant.

 Contact

None.
PaymentStatus

Status detail for the Registrant's payment. Will indicate whether the Registrant has paid, or if payment is still due.

 string

None.
RegistrationStatus

Status detail for the Registration. Indicates whether the registration for the event is: Completed, Incomplete, Abandoned, Canceled, Balance Due.

 string

None.
ModifiedDate

Last modified date (UpdatedOn) for the Registrant.

 date

None.
