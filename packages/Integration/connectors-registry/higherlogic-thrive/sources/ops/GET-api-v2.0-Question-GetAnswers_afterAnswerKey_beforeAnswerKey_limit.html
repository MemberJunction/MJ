GET api/v2.0/Question/GetAnswers?afterAnswerKey={afterAnswerKey}&beforeAnswerKey={beforeAnswerKey}&limit={limit}

Returns a specified number of answers using the afterAnswerKey or beforeAnswerKey as a starting point. If both keys are put in the request, the afterAnswerKey will take precedence.

Request Information

URI Parameters

NameDescriptionTypeAdditional information
afterAnswerKey

The answerKey to use as a starting point, returning the next set of answers after this answer. This answer will not be included in the response.

 globally unique identifier

None.
beforeAnswerKey

The answerKey to use as a starting point, returning answers before this answer. This answer will not be included in the response.

 globally unique identifier

None.
limit

The number of answers to return. Default is 10, max is 50.

 integer

Default value is 10

Body Parameters

None.

Response Information

Resource Description

This endpoint will always return in the same order, returning the best answer first if one exists, then least recent to most recent. The afterAnswerKey will provide answers created after the answer specified. The beforeAnswerKey will provide answers created before the answer specified. The only time the order will not be based on date is when there is a best answer in the thread.

PaginatedAnswers
NameDescriptionTypeAdditional information
Answers

The set of answers specified in this particular paginated set

 Collection of Answer

None.
HasMoreAnswers

Whether or not there are more answers that continue on after this paginated set. Depending on the order of items requested, this could mean the next answer was published more or less recently than the last answer in the set

 boolean

None.
Next

Specifies a relative path to select the next set of paginated items based on the current set.

 string

None.
Previous

Specifies a relative path to select the previous set of paginated items based on the current set.

 string

None.

application/json, text/json
