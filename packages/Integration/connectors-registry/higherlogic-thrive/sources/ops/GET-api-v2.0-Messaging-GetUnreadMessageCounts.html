GET api/v2.0/Messaging/GetUnreadMessageCounts

Returns a key-value pair of ContactKey and Unread Message Count. Includes Inbox Messages, Friend Requests and Community Invitations.

Request Information

URI Parameters

None.

Body Parameters

None.

Response Information

Resource Description

Dictionary of globally unique identifier [key] and integer [value]

Response Formats

application/json, text/json

Sample: 
{
  "9ea1607c-dcae-4a7e-8a2f-396eaeb0544a": 2,
  "b8019ea4-5060-413e-96a6-c0b78b014f59": 4
}

application/xml, text/xml
