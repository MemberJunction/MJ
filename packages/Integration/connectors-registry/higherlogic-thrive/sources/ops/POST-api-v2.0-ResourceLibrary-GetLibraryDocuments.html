POST api/v2.0/ResourceLibrary/GetLibraryDocuments

Returns Library Documents according to the optional filter values. Results are returned in Descending Date order.

Request Information

URI Parameters

None.

Body Parameters

DaysBack: (Optional) Integer value - defaults to 30. LibraryKey: (Optional) Guid value - if not included, Documents will be retrieved from all Libraries. IncludeStaff: (Optional) Boolean value - if not included, defaults to true. MaxRecords: (Optional) Integer value - defaults to 10.
