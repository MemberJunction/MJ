POST api/v2.0/Discussions/PostToDiscussion

Post a Message to the specified Discussion.

Request Information

URI Parameters

None.

Body Parameters

NameDescriptionTypeAdditional information

 string

Required

Max length: 255
Body

Required
DiscussionKey

 globally unique identifier

Required
