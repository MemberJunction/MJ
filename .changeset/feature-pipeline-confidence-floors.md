Feature Pipelines resist prompt injection: an output can declare a confidence floor (`MinConfidence` with `OnLowConfidence: 'null' | 'fail'`), below which it is withheld (its Feature Value records the abstention with no value, write-back clears a target value the pipeline wrote and keeps a person's, `BelowConfidenceOutputs` on the result, `BelowConfidence` in the run summary) or the record fails as `BelowConfidence`; an LLM pipeline can opt in (`Context.RecordAsUserMessage`) to send the record's context fields as a JSON user turn, separate from the template's system turn; golden-set cases can be `Required` (a wrong one refuses the version) and can expect an abstention (`ExpectAbstain`), and `specification` cases stay outside the label-quality record. An abstention never clears or retires a person's value, even on a run that overwrites human values, and a column that does not allow null keeps its value (`withheldKeptFields`); `ValidateSpec` refuses a floor on a whole-answer (`$`) output beside other outputs; a golden-set `specification` case must be `Required`. Scoped runs given lower-case UUIDs now load their records and find their watermarks (record IDs are matched through the new `RecordIDs.Key` export of `@memberjunction/record-set-processor-base`), instead of sending blank records to the model and recomputing them. A version refused for a wrong required golden case now says which: the steward's plan, the run gate's refusal and the version save check name each wrong case and output (`MJFeaturePipelineVersionEntityExtended.DescribeShortfall` / `RequiredFailuresOf`, read from the stored `ResultDetails`), and the run gate leaves out the "change the threshold" remedy that cannot fix it; `RequiredCaseFailure` and `GoldenSetResultDetails` now live in `@memberjunction/feature-pipelines` (no longer exported by `@memberjunction/testing-engine`). Feature value keys and backfill matching use the shared `RecordIDs.Key`. The Bulk Operations run dialog shows each withheld output as "withheld (below confidence)" beside the record's changes.
