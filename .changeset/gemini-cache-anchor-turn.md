Every Gemini request now opens with a fixed user turn ("Proceed with the task described in the system instructions.") and a short model turn, unless the conversation already opens with that turn. Gemini's implicit cache reuses a previous request only when the new request repeats it past the system instruction into the first `contents` turn; a match on the system instruction alone is not reused. An agent loop's first and second calls began with different turns (the first call's only turn is per-turn state that the second replaces), so the second call never hit the cache. Measured on Gemini 3.8 Flash with a ~20k-token system instruction: 0 of 8 second calls hit without the fixed turn, 7 of 8 with it, each caching all but the last ~2,050 tokens of the previous request. In Skip, second calls went from 0% to 76–84% cached. A user turn of only empty text is dropped (as an empty model turn already was), so a request whose only user message is empty never ends on the anchor's model turn, which Gemini rejects. Vertex AI shares this code.
