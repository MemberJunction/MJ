Custom entity forms fit a 375px phone: tab strips give way to the section picker instead of spilling past the edge, hero action rows (Run / Refresh / Export / Re-run) drop under the title, the title block stacks over the Run button on Actions, AI Prompts and Templates, metadata rows on Queries wrap, and the Entities header wraps its stat tiles two per row. All rules sit under the existing 768px breakpoint; desktop is unchanged. The hero header panels (Users, Companies, Employees, Conversations, AI Agent Categories) let a long title wrap instead of scrolling the panel column sideways, and the records region fills the full height on phones now that its layout runs headerless. `@memberjunction/ng-ui-components` gains `mj-section-picker`, the phone replacement for a section rail or tab strip: one button naming the current section that opens a searchable Sections bottom sheet. On phones the container-form heroes (Actions, AI Prompts, Templates, Queries, AI Agents, AI Agent Sessions, Action Execution Logs, AI Prompt Runs) collapse to the icon, name, status and primary action, with everything else behind one tappable summary line; the Queries hero takes the same card surface as the others. The forms built from stacked accordions (AI Prompt Runs, AI Prompts, Actions, Templates, Queries, Action Execution Logs) show one section at a time behind the section picker, with nested accordions rendered as plain headed blocks, so content sits on the page gutter instead of several paddings in. AI Prompts' Models and Execution History become cards, and AI Agents' tab nav becomes the picker. `@memberjunction/ng-ui-components` gains `mj-accordion-sections` and a flat mode on `mj-accordion-panel`; opening a section emits `ExpandedChange(true)`, so panels that load on first expand still load. `@memberjunction/ng-base-forms` drops the layout row's desktop gap on phones. On phones `mj-dialog` picks its presentation from `Size` and `Role`: alert dialogs (the confirm service) and `sm` / `auto` dialogs open as a bottom sheet with full-width 44px actions, larger and `Width`-set dialogs go full-screen on `100dvh` with pinned title and actions and safe-area padding; the close button is 44px. The form toolbar's Discard and Delete confirmations move from hand-built markup to the shared `mj-confirm-dialog` (same wording; a dirty record with no named field changed now reads "You have unsaved changes" instead of "0 unsaved changes"), so they get the phone sheet too. The Templates form's Test Template dialog shows each parameter as a card on phones instead of a table that clipped its last column. `mj-window` gets the same phone full-screen treatment (100dvh, safe-area insets, 44px close, its inline drag position no longer leaking onto phones), and the Actions test harness moves from hand-built markup onto `mj-dialog` with Execute Action, Reset and Clear Results as footer buttons (the harness gains `ShowActionButtons` and `StateChange` so a host can render its actions). On phones a flat accordion builds its lazy body only when its section is picked, the harness window drops its minimize and maximize buttons, and AI Agent Runs and Entities follow the breakpoint when the window is resized. Both section pickers name the active section's unsaved changes, errors and warnings in their accessible name, report `aria-expanded`, and order a sheet row's indicators the way the button does; the Prompt Run status chip uses the `--mj-status-*` tokens. The Actions test harness now mounts only while its dialog is open, so it no longer loads on every Action form or reopens showing the last run; on phones it drops its own padding and the heading that repeated the dialog title (`ShowTitle`), and Skip Action Log is the shared `mj-switch`, reachable by keyboard. `mj-dialog` opens on the first field the browser can actually focus, skipping hidden and `inert` ones. `@memberjunction/ng-ui-components` exports `IsPhoneViewport` / `WatchPhoneViewport`, and the AI test harness uses them to show one pane at a time on phones: the chat, or the settings sidebar at full width, with its header wrapping and 44px buttons. A danger `mj-confirm-dialog` (including `MJConfirmService.ConfirmDelete`) now opens with focus on Cancel instead of the destructive button, so an Enter pressed as it opens does not delete or discard.
