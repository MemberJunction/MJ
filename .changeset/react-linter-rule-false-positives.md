Fix false positives in the runtime and type rules found in Skip's audits of AI-generated components. `required-queries-not-called` recognizes RunQuery through any reference to the rq service (`utilitiesRef.current.rq`, an alias of it, a destructured or renamed `rq`) and optional calls. `query-result-field-access-validation` tracks query result variables by binding, so a same-named variable in another function no longer inherits the query's fields. `noisy-settings-updates` flags a save only when its handler is wired to a per-keystroke event (onInput, or onChange on a text input, textarea or Input-like component), so a save on Enter from a key handler is no longer flagged. It recognizes `onSaveUserSettings?.(...)` and `useCallback` handlers, skips a save inside a `setTimeout` or `debounce` callback, and its debounce check now works (it compared against `"[object Object]"`). `component-usage-without-destructuring` accepts `components || {}`, `components ?? {}` and `props.components`.

Fix type-inference false positives in `type-mismatch-operation` and `type-compatibility`. A variable is now typed where it is read (its enclosing functions) instead of taking the type of any same-named variable elsewhere, so `m - 1` in `for (let m = 1; ...)` is no longer "arithmetic on object" because a helper declared `const m = ... || {}`. String-method checks respect `typeof` guards like the arithmetic checks do, and a guard in a ternary's test now narrows its consequent (`typeof a === 'string' ? a.localeCompare(b) : a - b`). A state setter called with a functional updater (`setPage(p => p + 1)`) no longer types the state as a function, and a later write of another type (an assignment, or `setTier(null)`) widens the variable's type instead of replacing it. `for...of` / `for...in` variables are unknown, not undefined.
