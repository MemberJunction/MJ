Discovery no longer caps a sampled string width at 4000 when twice the observed value exceeds it: past 2,000 observed characters it returns MAX, and `MergeLength` treats MAX as unbounded (1,001–2,000 observed keeps 4000, which holds 2–4x it); fixes that lived only in a deployed patch set — the first-discovery heal (now scoped to the objects it missed, reported as a warning if it fails, and reporting the first pass's counts), the run-boundary watermark pin, the prefetch-cache leak — are in source with pinning tests; a relative import without `.js` is a guarded boot error. A keyset scan whose page hits the fetch timeout is suspended for the run (no retry, no page-skip re-request stacked on the abandoned attempt) and resumes from its persisted key next run, where the page is retried; the record-map and run-detail saves enrol in an active write group like the entity saves. A run that leaves objects INCOMPLETE — suspended, aborted, pages skipped or overlapped, or short of the source's stated total — names them in its completion message after any error count, and the REST base now passes the API's stated total out as `SourceTotalRecords`.
