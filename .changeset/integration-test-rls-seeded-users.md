Integration Test TestType — seed dedicated RLS test users so the multi-user isolation checks run deterministically (instead of skipping on admin-only databases).

Previously the strongest RLS checks (RLS3 fingerprint divergence, RLS4 server-superset no-cross-serve, RLS5 live no-leak) skipped on `mj_integrations` because every real user is RLS-*exempt* (internal users hold Developer/Integration, which grant unfiltered read — "most-permissive-wins" erases the scoped clause), and the suite otherwise leaned on the incidental `anonymous@magic-link.local` account.

- **New version-controlled seed metadata** (`metadata/roles`, `metadata/entity-permissions`, `metadata/users`): a purpose-built role **"Integration Test: RLS Scoped Reader"** that grants read on `MJ: AI Agent Runs` scoped by the existing `UI: Own AI Agent Runs` filter (`UserID = '{{UserID}}'`) **and nothing else**, plus three inert, login-less test accounts — `it-rls-a@` / `it-rls-b@integration.test` (each in ONLY that role → genuinely scoped/non-exempt) and `it-nogrant@integration.test` (no roles). Because A/B are the only non-exempt users, `discoverRlsFixture` now finds a real divergent pair and **RLS3/RLS4/RLS5 execute for real** on any DB the seed is pushed to.
- **Three new deterministic checks** in the `rls-isolation` bundle (IT06), which reference the seeded users by email (via `RlsFixture.SeededScopedA/B/NoGrant`, resolved in `discoverRlsFixture`) so they don't depend on which pair discovery happens to pick: **RLS8** (the two scoped users get distinct non-empty clauses + distinct cache fingerprints), **RLS9** (a live RunView as a scoped user returns only its own rows), **RLS10** (the no-grant user is served ZERO rows — the deterministic negative case that replaces the old reliance on `anonymous@magic-link.local`). Each skips-as-pass when the seed isn't present, so nothing breaks before the metadata is pushed.
- Verified live against `mj_integrations`: `rls-isolation` is now **9/9** via both the tsx script and the `IntegrationTestDriver` (IT06), with RLS3/4/5 running rather than skipping. Package unit tests **121 pass** (fixture-resolution unit tests added; coverage guard bumped `rls-isolation` 6 → 9). Additive / back-compat.

Note: the seeded accounts are pushed by any `mj sync push` of `metadata/`, so they appear in every environment's user list. They are `Type='User'`, have no auth linkage (no password / magic-link), and grant only scoped read on one entity — inert by construction, clearly named "Integration Test …", safe to delete. The seeded no-grant user is now also available if the pre-existing server-cache S31 cross-user check is ever reworked off the incidental anonymous user (out of scope here).
