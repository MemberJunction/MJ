feat: the conversation sidebar gains modifier-click multi-select, bulk move/pin, sort buttons and a search clear button

Ctrl/Cmd-click toggles one conversation and Shift-click selects the range between it and the last row picked, both starting selection mode on their own; a range follows the order the list renders and never reaches rows hidden inside a collapsed folder or section. Both modifiers treat the conversation that is open as part of what you are picking: a Ctrl-click that starts a selection takes it along, so it moves and drags with the rows chosen beside it, and a Shift-click with nothing picked yet ranges from it, so one click highlights a span. A row picked with Ctrl takes over as the range start from there, and the open conversation is seeded only once — deselect it and it stays gone. Selection is shown the way a file manager shows it — the row itself carries an accent tint and an inset accent bar, and the per-row checkbox column is gone; the open conversation keeps its solid accent fill, so a row that is both open and selected still reads as the open one. Selection mode closes itself once the last row is deselected, and Escape leaves it; the ⋯ menu's "Select Conversations" entry is gone, since selection now starts from the list itself (a modifier-click, or Select All in the empty-space menu). Clicking the empty space below the conversations drops the selection too, as clicking blank space in a file browser does. Every action lives in one right-click menu, replacing both the per-row ⋯ menu's contents and the bottom selection bar: right-clicking a selected row acts on the whole selection (a "3 selected" header, Pin, Unpin, Move to folder ▸, Delete 3), right-clicking any other row acts on that row alone and leaves the selection untouched, and the ⋯ button opens the same menu for touch and mouse-only users. The menu also carries Share, and it opens the same `mj-resource-share-dialog` the chat header and the dashboards use — one conversation or several. That dialog now accepts a set of resources through a new `Contexts` input: it merges everyone's access across them, labels a person whose access covers only some ("2 of 3") or sits at differing levels ("Mixed"), and applies every action — add, level change, removal — across the whole set. `Context` keeps working unchanged for a single resource, so dashboards and the chat header are untouched. Conversations you do not own are left out of the set and reported through the dialog's new `Notice` input. Right-clicking a folder offers New Subfolder, Rename and Delete — so the hover icons on folder rows are gone — and right-clicking empty space offers New Conversation, New Folder and Select All. Bulk actions keep the selection so a second action can follow, and report any conversations they could not change. A selection can also be dragged: grabbing any selected row drags the whole selection onto a folder or onto Ungrouped, moving every one of them in a single batch, while grabbing an unselected row drags that row alone and leaves the selection untouched. A conversation row is a drop target for the folder it sits in, so dropping onto the conversations inside a folder files the drag there as well, and dropping onto an ungrouped conversation moves it out of its folder; conversations already in the destination are left alone rather than re-saved. A Date / Name button pair under the search box sorts the Pinned section, every folder and the Ungrouped list together — clicking the active button flips the direction — and the choice is persisted alongside the existing folder collapse state and group-by mode. The search box gains a clear button, and Escape inside it clears the query.

`ConversationEngine` gains `MoveMultipleConversationsToProject` and `PinMultipleConversations`, which save one conversation at a time so a single rejection cannot fail the batch, roll a failed conversation's fields back in memory, and emit the updated list once for the whole batch instead of once per conversation.
