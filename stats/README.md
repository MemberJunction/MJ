# Repository Stats

Lines-of-code snapshots over time, counted with [cloc](https://github.com/AlDanial/cloc) over git-tracked files
(`node_modules`, `dist`, and other ignored paths are excluded automatically). Every count is split into
**hand-written** vs **generated** — deterministic tool output such as CodeGen entity classes/forms/resolvers,
`mj codegen manifest` registrations, mj-sync metadata migrations, baseline consolidations, pg-migrate
conversions, connector metadata, and lockfiles. The exact patterns live in [repo-stats.mjs](repo-stats.mjs).

To record a new snapshot (or use the `/update-stats` Claude command, which adds narrative analysis):

```bash
node stats/repo-stats.mjs              # current tree
node stats/repo-stats.mjs <commit>     # backfill a historical commit
node stats/repo-stats.mjs --render     # re-render README from data.csv (no recount)
```

## Latest analysis (2026-09-01)

Hand-written source (TS+JS+HTML+CSS+MD) grew from 2,532,735 to 2,602,482 lines (+2.8%) over
the month since 2026-08-01, a net figure that hides two much larger offsetting moves. TypeScript
hand-written code grew by 114,439 lines while HTML hand-written code *shrank* by 121,220 —
almost a wash at the source-group level, but for entirely different reasons.

The HTML drop is a single deletion, not a trend: `packages/Integration/connectors/reference/ym-api-reference.html`
(146,904 lines) was removed in PR #3385, "chore: remove connector source duplicated by the
Integrations repo." That file was a vendored API reference doc that had been inflating the HTML
bucket for a while; connector source of truth now lives in the separate Integrations repo. The
TypeScript growth is real feature work spread across ~250 merged PRs this cycle — the TaskGraph
system (`TaskGraphDispatcher`, `TaskGraphService`, `TaskClaimStore`, phases 0–2 of its legacy
retirement and truthful-engine work), a cluster of Integration-engine reliability PRs (adaptive
fetch gating, prefetch pipelining/concurrency, per-entity write chains, batched-write flush
ceiling, RSU retry budget), the Workflows canvas and human-in-the-loop editor, realtime/ElevenLabs
voice-session hardening, and new Angular components (hierarchy-tree, graph-view, form-chrome
layering, record-attachments).

SQL grew by 240,009 lines (105,114 hand-written, 134,895 generated), reflecting the steady v6.1
migration cadence: AI Agent Harness Foundation, the TaskGraph payload/claim-column and
skipped/exclusive-group migrations, Durable EntityAction Dispatch, Query Entity Materialization,
a hierarchy-views/FormChromeRule regeneration, and several rounds of `Metadata_Sync` migrations
(each paired with its PostgreSQL mirror under `migrations-pg/`). Markdown hand-written content grew
63k lines, split between planning docs under `plans/` (memory-leak audit, TaskGraph/flow-agent
unification, conversation-detail windowing, API-key row filters) and per-package `CHANGELOG.md`
files generated by the changesets release tooling.

The "Other"/YAML bucket jumped 45,026 lines, almost entirely `pnpm-lock.yaml` (+49,302), the
lockfile produced by PR #3466's npm→pnpm cutover. This looks like a classification gap:
`GENERATED_PATTERNS` already treats `package-lock.json` as tool-emitted output, but the repo's
new `pnpm-lock.yaml` isn't covered by any pattern, so this month's entire cutover reads as
"hand-written." Worth adding a `pnpm-lock.yaml` pattern (and backfilling) so lockfile churn stops
distorting the hand-written trend going forward. The two large `generated/` TypeScript files
(`MJCoreEntities/.../entities/__mj.ts`, `MJServer/.../graphql-schemas/__mj.ts`) each show ~100k+
lines of raw diff churn but net out close to flat — a full CodeGen regeneration during the v6.1
cycle rewrote them rather than growing them.
